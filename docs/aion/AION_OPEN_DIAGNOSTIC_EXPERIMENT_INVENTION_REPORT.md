# AION Open Diagnostic-Experiment Invention

## Result

AION now constructs an adaptive information-producing experiment when an
observed failure cannot distinguish candidate, evidence, environment and critic
origins. No experiment workflow was supplied.

Private procedure:

`procedure_open_diagnostic_experiment_invention_v1`

Promoted delayed procedure:

`procedure_delayed_diagnostic_experiment_runtime_promotion_v1`

## Experiment synthesis

All four worlds initially exposed the same unresolved prediction failure. AION
formed four competing origin hypotheses and composed available read-only
measurements into an adaptive tree by maximizing expected information gain.
It rejected repeating the original observation, increasing intervention
magnitude without additional origin information and consulting a hidden failure
label.

The invented experiment was:

`ADAPTIVE_CROSSOVER_AUTHORITY_TRIANGULATION`

Its possible measurements were:

1. execute an alternate candidate on the same evidence;
2. reacquire evidence from the same authority;
3. compare an independent outcome without the current critic; and
4. fit a changed rule and require a later retest.

The experiment was committed before sealed outcomes were revealed. Its adaptive
tree required a mean 2.25 information actions rather than executing all four,
reducing information cost by 43.75%.

## Security and delayed promotion

The validator rejected experiments requesting network writes, filesystem or
process access, unbounded actions, post-outcome commitment, forced multi-fault
generalization, guessing unknown signatures or using hidden labels.

The experiment digest
`68d88cf15ea8b91ea4e8773f33a847204d2429540f74f73e88b7a8509ead4ae9`
remained private until all four public traces were reacquired after the
five-minute boundary. Every committed diagnosis was reproduced, promoting
`procedure_delayed_diagnostic_experiment_runtime_promotion_v1`. A fresh runtime
verified the digest, diagnosed all four single-origin signatures and preserved
multi-fault abstention without private invention state. The public payloads were
stable, establishing delayed retained execution rather than external change.

## Boundary

This is bounded diagnostic-experiment invention. The four origin hypotheses,
read-only measurement atoms and sealed outcome authority remain engineered. It
does not establish unrestricted scientific experimentation or AGI.

The next removal target is open measurement-operation invention: when the
adaptive experiment needs evidence that no retained measurement action can
produce, AION must privately implement a new bounded measurement, prove its
information value and safety, and transfer it across unrelated diagnostic
problems before runtime promotion.
