# AION HexCore — Residual-Driven Primitive Invention Arena v5

## Status

Arena v5 is internally promoted as:

`procedure_residual_driven_primitive_invention_v5_35b31ad85c20`

Parent:

`procedure_open_experiment_program_arena_v4_7b66f2843ca9`

Arena v5 addresses the principal Arena v4 limitation: the complete program
grammar could be criticized, but AION could not construct a new executable
primitive when that grammar failed.

## Research question

Can AION detect systematic residual structure outside its retained action
grammar, construct a private executable representation, actively falsify it,
control its complexity, transfer it to renamed projects and abstain when the
larger meta-grammar is still inadequate?

## Architecture

```text
retained Arena v4 grammar exhausted
  -> structured residual detected
  -> private model-family challengers
  -> maximum-disagreement outcome queries
  -> parameter fitting + description-length pressure
  -> held-out chronological validation
  -> security and complexity scan
  -> independent-process execution
  -> source-disjoint transfer
  -> CAU promotion, rollback or abstention
```

The old grammar contained raw, mean, median, clipping and lag operations. It
could not represent either the nonlinear development response or the
state-carrying temporal response.

## Invented primitive implementations

### Nonlinear polynomial primitive

AION selected a fifth-degree polynomial implementation:

```text
primitive_da3806a71ff8561d
```

Its learned approximation was:

```text
y = -3.40e-17
    + 0.997718 x
    + 1.67e-16 x^2
    - 0.162831 x^3
    - 3.81e-17 x^4
    + 0.006727 x^5
```

The negligible even coefficients were learned rather than hard-coded. The
primitive approximated the previously unexpressible nonlinear response while
remaining within the eight-parameter complexity ceiling.

### Stateful affine primitive

AION also invented an explicitly state-carrying representation:

```text
primitive_169b31b28601ccaf
```

with learned transition:

```text
y_t = 0.15 + 0.55 x_t + 0.65 y_(t-1)
```

This is materially different from fitting a static input/output curve. The
primitive stores and recursively updates an internal continuous state.

## Active falsification and model selection

Candidate families included polynomial programs of degrees 1, 3, 5 and 7 and
a stateful affine program. AION selected environment queries where the three
strongest candidates disagreed most. Incorrect candidates were recorded as
counterexamples rather than collapsed into a generic failure.

Selection minimized:

```text
training MSE + 1e-6 * description_length
```

The complexity term prevented an unnecessarily larger polynomial from winning
for a negligible training-only improvement.

## Independent executable verification

Accepted implementations were serialized as data and passed to a fresh,
isolated Python interpreter that had not imported the training implementation.
The interpreter executed only the two admitted forms:

- polynomial evaluation; and
- stateful affine recurrence.

Filesystem, network, dynamic-execution and authority-write operations were not
present in the executable schema.

## Source-disjoint transfer

The two learned primitives were tested on six renamed sealed worlds:

- three nonlinear-response worlds; and
- three stateful-feedback worlds.

Only two confirmation queries were allowed per sealed world before the
primitive was selected. The remaining cases were revealed solely to the
independent interpreter after selection.

The stateful primitive recovered its independently generated coefficients to
floating-point precision. The nonlinear primitive achieved mean sealed RMSE of
approximately 0.000707 on each nonlinear transfer world.

## Meta-grammar criticism

An additional discontinuous sign-response world was deliberately outside both
the polynomial acceptance envelope and the stateful-affine explanation. The
best challenger produced validation RMSE 0.206 against a 0.015 ceiling. Arena
v5 rejected it and abstained.

Therefore, primitive invention did not become a license to accept the best
available curve when no candidate was operationally adequate.

## Security and persistence

Four malicious implementation proposals requested dynamic Python execution,
network access, filesystem writing or authority override. All four failed the
schema and security gate before execution.

Both primitive implementations, their hashes, authority records, generation
record and champion survived complete runtime reconstruction with zero
relearning.

## What this advances

The cognitive progression is now:

```text
Arena v3: learn when a complete repair is needed
Arena v4: compose a new action from known primitives
Arena v5: construct a new executable primitive when known primitives fail
```

This is a bounded but important representation-learning advance. The system is
no longer restricted to recombining the Arena v4 vocabulary for these two
continuous families.

## Claim boundary

Arena v5 does not demonstrate unrestricted operator invention. The polynomial
and stateful-affine meta-families, query pool, controlled outcome generators,
parameter ceilings and evaluator were engineered. The sealed worlds were
source-disjoint but internally administered.

The correct claim is residual-driven construction of two executable continuous
primitive classes with active falsification, source-disjoint transfer,
independent-process verification and OOD abstention. It is not AGI, autonomous
scientific discovery or independent external certification.

## Next decisive stage

The highest-priority remaining gate is no longer another internal operator
family. AION must connect this learning loop to independently owned delayed
outcomes:

1. externally maintained repository tests;
2. later public sensor or scientific observations;
3. independently changing databases or controlled services;
4. human-authored delayed document questions; and
5. multi-rater human outcomes for social and creative work.

The same commitment, falsification, security, abstention, transfer, restart and
CAU gates must remain in force. Internal evaluators must not authorize the
external capability claim.
