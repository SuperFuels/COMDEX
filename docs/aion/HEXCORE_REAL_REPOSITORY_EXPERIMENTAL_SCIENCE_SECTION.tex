\section{Real-Repository Experimental Science}
\label{sec:real-repository-experimental-science}

\subsection{Objective}

AION now applies causal-scientific learning to real COMDEX and Photon source
artifacts:
\[
\begin{aligned}
\text{broad goal and Git evidence}
&\rightarrow \text{private sandbox}\\
&\rightarrow \text{candidate code intervention}\\
&\rightarrow \text{independent property outcome}\\
&\rightarrow \text{recursive repair invention}\\
&\rightarrow \text{hidden verification}\\
&\rightarrow \text{repair isomorphism and EVI curriculum}.
\end{aligned}
\]
The live repository is never modified.

\subsection{Intervention Inference}

For candidate change \(a\), intervention status is inferred from both artifact
and outcome transitions:
\[
\Delta_{\mathrm{source}}(a)
=
\mathbb{1}[H_a\neq H_0],
\qquad
\Delta_{\mathrm{outcome}}(a)
=
\mathbb{1}[\mathbf{T}_a\neq\mathbf{T}_0].
\]
A change is treated as an experimental intervention only when both are true.
Intervention inference was correct for 100\% of outcome-changing candidates.

Every candidate is compiled directly in a fresh subprocess namespace. This
prevents stale bytecode or module caches from contaminating causal attribution.
Public property tests guide challenger construction; hidden properties are
opened once for the selected candidate.

\subsection{Adaptive-MDL Repair Construction}

Repair proposals are ranked under
\[
\mathcal{C}(p)
=
L(p)+\lambda_rR(p)+\lambda_eE(p),
\]
where \(L\) is description length, \(R\) is declared risk, and \(E\) is
execution cost. If no atomic repair passes, atoms are recursively composed in
increasing cost order.

The Photon serialization project required two changes: Unicode preservation
and canonical key ordering. Neither atomic patch passed independently. The
two-edit composition passed public and hidden deterministic roundtrip tests.

\subsection{Repair Isomorphism and Curriculum}

Verified repairs are indexed by abstract failure/outcome topology. On a
held-out numerical symbol family, the retained prior reduced repair attempts
from three to one, a 66.67\% reduction.

Curriculum priority is
\[
\operatorname{priority}(T)
=
\frac{\Delta U(T)}
{\operatorname{descriptionCost}(T)+\operatorname{risk}(T)}.
\]
The three real-source projects received unique priorities. After the second
project, a fresh process reconstructed the checkpoint and verified the
completed-project list and outcome hash.

\subsection{Claim Boundary}

The source and Git histories are real, but fault injection, patch atoms,
property tests, goals, cost weights, and evaluator remain engineered. AION did
not yet synthesize unrestricted patches from raw source. This demonstrates
bounded repository experimentation and repair invention, not unrestricted
software engineering or AGI.

\subsection{Next Frontier}

The next stage removes supplied patch atoms and injected faults. AION must learn
from naturally occurring failing tests or historical CI outcomes, locate edit
sites, synthesize typed sandbox patches, invent falsifying tests, compare
against hidden historical repairs, transfer to another repository, and operate
over multi-hour projects with delayed external outcomes and human approval
points.
