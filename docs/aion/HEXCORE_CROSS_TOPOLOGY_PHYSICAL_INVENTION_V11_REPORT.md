# Arena v11: Cross-Topology Physical Invention

Promoted: `procedure_cross_topology_physical_invention_v11_928b71e4fa63`.

AION received Acrobot pixels without joint colors, link colors or numerical
state. Intervention identified two joints, two links and the topology
`fixed pivot -> moving hinge -> outer link`. Six stateful controllers competed.

The fastest development controller (`inner_phase`) solved textbook dynamics but
failed the alternate dynamics and was rejected. A private structural-shift
curriculum selected a newly useful `inverse_outer_phase` controller. Fresh
sealed seeds then produced:

| Measure | Result |
|---|---:|
| Textbook Acrobot | 6/6 |
| NeurIPS dynamics | 6/6 |
| Cold control | 0/12 |
| New state primitive | outer-link angular phase |
| Pre-action commitments | 1,617 |
| Numerical observations | 0 |
| Unsafe actions | 0 |

This demonstrates failure-driven representation revision across an articulated
topology. Component primitives, controller meta-grammar, seeds and gates remain
development controlled; it is not external certification, robotics or AGI.
