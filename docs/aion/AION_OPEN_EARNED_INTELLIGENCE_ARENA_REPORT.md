# AION Open Earned-Intelligence Invention Arena

## Result

The arena promoted `procedure_open_earned_intelligence_invention_v1`.
AION received opaque three-input demonstrations with zero supplied relation
types and zero supplied operator labels. It searched an executable Boolean
expression meta-grammar, selected maximum-disagreement interventions, committed
before each outcome, and tested the learned relation on renamed schemas.

## Scientific rejection and revision

The first challenger was rejected. Seven of eight observations leave two
Boolean functions observationally compatible, so treating all minimum-
description champions as certain produced a 5/6 result. The revised procedure
made the epistemic distinction explicit.

Four simple relations generalized before reveal. In one world, two equally
simple explanations disagreed, so AION abstained and requested the withheld
consequence. In another, the shorter theory made a confident but incorrect
prediction. The independent consequence falsified it, the competing theory was
retained, and the repaired method transferred across a renamed opaque schema.

This establishes the following bounded loop:

```text
opaque demonstrations
  -> invent executable explanations
  -> intervene where explanations disagree
  -> predict or abstain before reveal
  -> accept counterexample criticism
  -> revise the method
  -> transfer to renamed inputs
  -> retain under HexCore authority
```

## Authority boundary

The relation and expression labels were not supplied. However, the Boolean
meta-grammar, three-variable topology, outcome oracle, and sealed worlds remain
development-engineered. This is evidence of bounded open method invention and
epistemically governed revision. It is not arbitrary-domain learning, AGA, or
AGI.
