## Critic failure

The inherited critic checked translation invariance, constant-series behaviour,
insufficient-data abstention and deterministic execution. A short endpoint
slope estimator passed every inherited check but failed a withheld boundary
contamination consequence:

\[
(1,2,3,4,5,6,7) \longrightarrow (1,2,3,4,5,6,1000).
\]

The expected robust trend remained $1$, while the accepted endpoint estimator
returned $166.5$. AION therefore treated the problem as critic inadequacy rather
than merely replacing the implementation.

## Property synthesis

The failure trace contained the original input, observed input, expected result,
actual result and changed indices. AION inferred:

1. exactly one observation had changed;
2. the changed observation was at a sequence boundary;
3. its displacement was large relative to the robust adjacent scale; and
4. a valid robust estimator should keep its output stable under that sparse
   contamination.

It rejected exact counterexample replay as instance-specific, global
translation as irrelevant, and permutation invariance because it destroys
temporal semantics. It then compiled the typed property
`SPARSE_BOUNDARY_CONTAMINATION_STABILITY`:

\[
\frac{|f(T(x))-f(x)|}
{\max\{s(x),0.05|f(x)|,10^{-12}\}}
\leq 0.25,
\]

where $T$ replaces the witnessed boundary observation by a bounded extreme and
$s(x)$ is a robust adjacent-difference scale.

The property language is declarative and capability classified. It cannot
import code, access the network or filesystem, launch processes, call a shell,
request an unbounded perturbation or invoke an external oracle.

## Cross-family proof

The new property first rejected endpoint slope and preserved
`ROBUST_MEDIAN_PAIRWISE_TREND` on World Bank and FRED GDP series. AION then reused
the same critic in an unrelated location-estimation invention. It rejected an
arithmetic mean and preserved a robust median on NOAA temperature and Treasury
exchange-rate series.

Thus the retained object is not a fixture-specific expected answer. It is an
executable criticism method that discriminates fragile and robust strategies
across different computations and public authorities.

## Delayed promotion

The property digest
`bd108fd178547e9087146b53cea7c3d14e02ec9186ca17b5d9dbe8e9ec8cda30`
was committed while the runtime critic registry remained unchanged. Development
and transfer authorized only a private challenger. After the five-minute
boundary, all four public authorities were reacquired. The property again
rejected both fragile implementations while preserving both robust
implementations, promoting
`procedure_delayed_property_critic_runtime_promotion_v1`.

A fresh `GovernedPropertyCriticRuntime` verified the installed digest without
accessing private synthesis state. It rejected endpoint slope with normalized
delta $165.5$, accepted robust trend with delta $0$, rejected arithmetic mean
with delta $141.857143$, and accepted robust median with delta $0$. The public
responses were stable during the interval, so the result demonstrates delayed
critic retention and re-execution rather than environmental change.

## Boundary

This is bounded open property-language invention, not unrestricted autonomous
criticism. The typed meta-grammar, candidate operator families, public
authorities and independent success labels remain engineered. The next removal
target is open critic-objective invention: AION must decide which behavioural
risk deserves a property when no labelled failure category or expected
invariance is supplied.
