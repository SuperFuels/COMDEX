# AION Recursive Action-Language Expansion

## Outcome

AION constructed a new private semantic atom after the retained action grammar
could parse and traverse evidence but could not infer a comparable time series
from incompatible JSON and CSV schemas. The private challenger is:

`TEMPORAL_NUMERIC_PROJECTION`

It remains excluded from the runtime registry until four later public
consequences confirm the exact committed implementation hash.

## Missing transformation

The preceding action language could retrieve JSON, enumerate pages and extract
XML evidence, but it could not construct a canonical temporal numeric relation
when container shape, field names, date resolution and number representation
changed. Fixed-column projection failed immediately under source-disjoint field
renaming. Selecting the first numeric column failed when identifiers, line
numbers, coordinates or unrelated measurements appeared before the intended
value.

AION therefore synthesized a new typed atom specification with a strictly pure
capability class. Its implementation:

1. Decodes bounded JSON or CSV bytes.
2. Discovers the record container.
3. Profiles every candidate field over actual values.
4. Scores temporal fields through name and parse evidence.
5. Scores measurement fields through numeric coverage and mission semantics.
6. Requires a confidence margin over the runner-up measurement.
7. Normalizes finite numbers through decimal semantics.
8. Preserves source row, source fields and body digest provenance.
9. Abstains on ambiguity, binary data, oversize input or malformed content.

The atom has no network, filesystem or process authority. Existing governed
adapters obtain bytes; the new atom performs only a deterministic transformation
over those bytes.

## Rejection and revision

The first private challenger was rejected. Although it succeeded on World Bank,
Treasury and FRED, it failed two self-generated properties concerning missing
and formula-like values, and its authority matcher rejected NOAA's legitimate
institutional subdomain. The successor recalibrated the minimum semantic score,
retained the ambiguity-margin gate, and generalized authority identity to
verified subdomains without adding a new authority family.

The promoted private challenger passed all six metamorphic properties:

- field-order invariance;
- missing values are never converted to zero;
- ambiguous measurement columns cause abstention;
- formula-like CSV cells are never executed;
- binary input causes abstention;
- capability-class escalation is rejected.

## Cross-authority transfer

The identical committed atom produced canonical temporal projections for:

| Authority | Representation | Inferred time | Inferred measure | Rows |
|---|---|---|---|---:|
| World Bank | JSON metadata array | `date` | `value` | 66 |
| U.S. Treasury Fiscal Data | JSON object collection | `record_date` | `exchange_rate` | 100 |
| Federal Reserve FRED | CSV | `observation_date` | `GDP` | 318 |
| NOAA NCEI | CSV | `DATE` | `TEMP` | 236 |

No source-specific field mapping was supplied to the atom. The World Bank task
was the development authority; Treasury, FRED and NOAA were source-disjoint
transfers.

## Two-stage promotion authority

Immediate success authorized only a private challenger; the runtime registry
remained unchanged. Each of the four episodes contained a five-minute
precommitment over the implementation digest, inferred time field, inferred
measure field and source outcome. After the elapsed boundary, AION re-fetched
all four authorities and reproduced those semantics. The 4/4 result permitted
HexCore to install the exact implementation under
`procedure_recursive_action_atom_runtime_promotion_v1`.

Installation records the atom digest, pure capability class, verified
authorities and CAU procedure. Any later failure leaves the runtime registry
unchanged.

A newly constructed `RecursiveActionAtomRuntime` then loaded only the promoted
registry, verified the implementation digest, discovered the atom by identifier
and executed it successfully over a fresh GDP CSV sample. It did not read the
private candidate registry or replay the development sources.

## Boundary

This is bounded recursive action-language expansion. AION synthesized a new
reusable semantic atom through an engineered meta-compiler; it did not write or
execute unrestricted Python. Micro-operations, missions, sources and gates
remain engineered. The next boundary is open micro-operation invention: private
implementation of a transformation not expressible by the current compiler,
verified through generated executable semantics, resource accounting,
source-disjoint transfer and delayed promotion without ambient authority growth.
