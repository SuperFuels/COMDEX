\section{Arena v10: Open Visual Control Invention}
\label{sec:arena-v10-open-visual-control}

Arena v10 removes two scaffolds from public pixel control: no task-specific
object color is supplied and no winning controller is supplied. AION first
intervenes, tracks candidate image components and selects the component that
maximises coherent motion while preserving approximate pixel population. It
considered 39 components and independently recovered the movable wheel feature.

Seven executable feedback expressions were recursively composed from constant,
sign, temporal-difference and position-threshold primitives. Public development
outcomes selected
\begin{equation}
 u_t=\operatorname{sign}(x_t-x_{t-1}).
\end{equation}
The abstraction was frozen and lifted from discrete MountainCar-v0 actions to
continuous MountainCarContinuous-v0 actions without changing its expression.
