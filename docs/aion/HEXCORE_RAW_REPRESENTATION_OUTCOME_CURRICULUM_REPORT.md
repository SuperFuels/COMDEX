# HexCore Generality Tracks — Raw Representation, Real Outcomes and Autonomous Curriculum

**Date:** 30 July 2026  
**Status:** Three governed promotions completed  
**Numbering policy:** Capability names replace overloaded phase numbers after Phase 63

## Executive result

AION has completed three connected capability tracks:

1. **Raw Event Representation Learning** — invent state and relation symbols from anonymous project-event streams without receiving labels such as `authority_stale` or `evidence_conflict`.
2. **Real Outcome Grounding** — treat neural, symbolic and language outputs as proposals until an independent executable, documentary, delayed or operational outcome verifies them.
3. **Autonomous Capability Curriculum** — measure its own capability map from externally scored outcomes, target the current weakest/highest-cost family, train private specialists and retain them across four generations.

These tracks connect representation learning, outcome learning and curriculum selection into one restart-persistent loop. They do not establish unrestricted AGI: the channel interface, finite action topology, task generators, proposal descriptor language and outcome authorities remain engineered.

## Photon and GlyphNet integration decision

The supplied Photon specifications establish two different artifact families:

- `.phn` and `.ptn` are Photon Language capsules/pages executed by the Photon runtime.
- `.photon` and `.pthon` are glyph-compressed Python expanded by the Python importer.

The new representation learner uses a data-only Photon Intermediate Representation (PIR) capsule. Invented transition rules compile into traceable `⇒` operations:

```text
invented state + anonymous operator role ⇒ invented next state
```

Photon remains a proposal and execution representation. HexCore verification and CAU remain the authority. The implementation does not mislabel glyph-compressed Python as Photon Language.

GlyphNet's append-only event ledger, stable event identifiers, source hashes, timestamps and graph edges are suitable future raw inputs. Semantic event labels already present in the ledger must be masked during representation-learning evaluation; otherwise labels such as `drift_report` would leak the vocabulary AION is meant to invent.

## Track 1 — Raw Event Representation Learning

### Research question

Can AION construct a useful state vocabulary from raw categorical event streams when:

- state meanings are not named;
- relation meanings are not named;
- every development and sealed domain uses different channel names;
- every domain uses different action names and value tokens;
- an out-of-family transition system must be rejected?

### Architecture

The learner performs:

1. raw before/action/after event collection;
2. anonymous channel-action effect-graph induction;
3. iterative structural colour refinement independent of identifier strings;
4. value orientation from observed interventions;
5. predictive-equivalence state aggregation;
6. action-conditioned transition relation induction;
7. traceable Photon PIR compilation;
8. structural transfer or explicit abstention.

Symmetric dimensions are intentionally represented as a shared structural role rather than assigned invented semantic stories. This produces five predictive state classes, corresponding to the number of active anonymous conditions, and thirteen supported transition classes. Evaluator meanings never enter the learner.

## Track 2 — Real Outcome Grounding

### Research question

Can the invented representation participate in decisions whose truth is determined outside AION's proposal system?

Four independent authority families were implemented:

- safe AST execution for generated code candidates;
- exact disk rereading for document evidence;
- delayed withheld observations for forecasts;
- an operational precondition monitor for executable workflows.

Proposal confidence is never an authority signal. AION may stop candidate search only after the selected external authority reports a verified consequence.

## Track 3 — Autonomous Capability Curriculum

### Research question

Can AION use independently scored outcomes to decide what it should practice next, improve evaluation efficiency and preserve earlier competence?

The curriculum controller computes, per family:

- verified accuracy;
- weakest-family accuracy;
- mean independent verification probes;
- trained/untrained status;
- a combined weakness score.

It then selects the current weakest/highest-cost family, generates a private source-disjoint curriculum, trains a reversible proposal-ranking specialist and performs backward-retention evaluation. The learner does not promote itself; the independent outcome authorities, sealed arena gates and CAU decide.

### Autonomous generation order

The learner selected:

1. delayed forecasting;
2. document evidence;
3. software execution;
4. operational execution.

All four generations improved the targeted verification cost and retained previously learned families.

## Authority and safety boundary

The request to remove guardrails was not implemented as removal of CAU, provenance, sandboxing, rollback or independent verification. Those controls are part of the experimental method: without them, AION could declare its own proposals correct and apparent self-improvement would not be measurable.

Capability was expanded instead:

- labels were removed from the learner;
- cross-domain field/action names were fully changed;
- outcomes came from independent mechanisms;
- the curriculum was selected automatically;
- the arena was expanded to 1,000 tasks;
- promotions remained reversible.

## Honest claim boundary

The results demonstrate a bounded but important chain:

```text
anonymous events
→ invented predictive states and relations
→ Photon proposal representation
→ independent real/controlled outcomes
→ capability map
→ targeted private curricula
→ retained efficiency improvement
```

They do not demonstrate ontology induction from arbitrary language, unrestricted tool creation, human-level commonsense, unconstrained long-running autonomy or independent AGI certification.

## Next decisive tracks

1. **Natural raw-event induction:** replace categorical channels with unstructured logs, documents and mixed-modality event records.
2. **Open topology invention:** vary dimensionality, coupled effects, latent variables and temporal persistence rather than transferring one four-channel graph.
3. **Live software outcomes:** evaluate patches in isolated real repositories using existing test suites and resource limits.
4. **Human-authored curriculum families:** introduce reading, code, science, social and creative tasks that were not emitted by the current generators.
5. **Substrate comparison:** compare replaceable 500M–3B open models inside the unchanged HexCore/Photon interfaces.
6. **Independent administration:** expose frozen commitments and budgets to an evaluator who did not build the system.

The next highest-value implementation is **Open-Topology Natural Event Induction**: infer entities, states, persistent versus temporary properties and causal relations from unfamiliar natural project logs while withholding both field names and the number of latent dimensions.
