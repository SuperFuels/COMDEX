# AION Open Tool and Environment Acquisition

## Result

The canonical AION runtime can now respond to an unfamiliar execution interface
by constructing and testing a private adapter rather than requiring the file
extension or adapter implementation to be supplied.

Promoted procedure:

`procedure_open_tool_environment_acquisition_v1`

## Capability

The acquisition path performs:

```text
unknown interface
  -> content-signature discovery
  -> safe adapter-candidate construction
  -> semantic property and counterexample generation
  -> privileged-operation rejection
  -> private execution
  -> evaluator-owned semantic outcome
  -> source-disjoint transfer
  -> interface-drift criticism and contract replacement
  -> persistent registry retention
```

Surface filenames and suffixes do not select the adapter. Development inputs
used opaque extensions and transfer inputs used unrelated renamed extensions.
The retained routing key is a content signature learned from execution outcomes.

use credentials, perform purchases, deploy software or execute unrestricted
generated code. Those are authority classes, not capability prerequisites.
