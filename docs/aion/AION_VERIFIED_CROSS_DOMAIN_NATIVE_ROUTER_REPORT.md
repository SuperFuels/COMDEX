# AION Verified Cross-Domain Native Router

## Promotion

`procedure_verified_cross_domain_native_router_v1` is internally promoted.

AION consolidated verified experience from five distinct cognitive surfaces into one replaceable proposal component:

1. hypothesis and experiment strategy selection;
2. full-stack component repair;
3. opaque tool and execution-adapter acquisition;
4. persistent natural-language mission interpretation; and
5. independently changing public-outcome response.

## Corpus and architecture

Fifty-five canonical trajectories were reconstructed from provenance-bearing runtime state rather than coarse result filenames. Each record contains a hashed situation, verified response, authority, cohort and exact source artifact. Thirty-two development trajectories trained three independent private heads; 23 source-disjoint or renamed trajectories were opened only for final transfer evaluation.

The replaceable component is:

```text
local 384-dimensional semantic representation
    -> three independent 384 -> 32 -> 5 private routing heads
    -> averaged specialist proposal
    -> HexCore execution/outcome verification
    -> accept or complete symbolic fallback
```

The ensemble has 37,455 learned parameters. Neural output is proposal-only. A wrong route cannot become knowledge or action authority, and removing the weights restores the complete pre-existing specialist search path.

## Live integration

`NativeAionCognitiveAdapter` now loads this component lazily during investigation. The route and calibrated uncertainty are included in the investigation and planning records, but remain explicitly marked `proposal_only`. Low-confidence or low-margin predictions abstain. The canonical runtime was restarted from its persistent checkpoint to activate the component.

## Boundary

This is verified cross-domain neural consolidation and useful transfer across five bounded AION cognitive domains. The local pretrained sentence encoder, domain schemas, existing specialists and evaluation authorities remain engineered. It does not demonstrate unrestricted task understanding or autonomous neural authority.
