# AION Remaining Development Roadmap — Post Arena v17

## Position

AION is no longer missing a basic cognitive loop. It already contains bounded,
governed implementations of persistent semantic memory, causal discovery,
world-model revision, active investigation, program and primitive invention,
software experimentation, open evidence acquisition, project recovery,
multimodal analysis, real local physical intervention, continual neural skill
retention and explicit abstention.

The remaining distance is **generality, duration, open representation,
independent outcomes and external authority**. More isolated demonstrations of
known skills will not close that distance.

The canonical cognitive runtime now unifies the Goal Engine, Theta/Tessaris,
HexCore governance, delayed outcomes, failure attribution, private challengers
and persistent learning in one restart-safe state machine. Runtime unification
is therefore complete as an architectural dependency. The capability-first
programme now concentrates on sustained autonomous use of that runtime across
unfamiliar goals. Independent administration remains an optional credibility
track rather than a prerequisite for internal capability development.

Runtime-native curriculum is now also operational. An immutable owner mission
can define bounded capability requirements and outcome authorities; the runtime
selects the lowest-confidence unmet capability, generates a subordinate goal,
learns from the returned consequence and continues after restart. The first
five-family campaign completed fifteen verified cycles and reduced transfer
queries by 68.75%. The remaining autonomy gap is no longer goal scheduling. It
is deriving the capability graph, tools and exercises from raw unfamiliar
missions without a finite development-authored task catalogue.

Open portfolio-to-mission induction is now promoted. Four real-file portfolios
produced four different dependency-graph sizes and 24 verified capability
cycles, with 41.67% lower transfer information cost and zero objective mutation.
The capability graph itself is therefore no longer always supplied. The next
gap is open execution acquisition: unknown formats, APIs and environments must
trigger documentation search, private adapter/tool construction, adversarial
tests and transfer verification inside the same mission rather than relying on
the current generic extractor registry.

The first bounded open-execution acquisition cycle is now promoted. It invented
five safe adapters across nine opaque/renamed interfaces, transferred with 75%
fewer trials, repaired an interface-family change and rejected every privileged
candidate class. Consequently this track is no longer the primary blocker.
Unknown tools should next appear naturally inside the multi-day arena; new
adapter families are added only when real project failures demand them.

The resumed main critical path is:

1. complete the active Arena-v15 duration gate and extend it across multiple
   heterogeneous missions and challenger generations;
2. add full-stack failure localization and private self-repair to the canonical
   runtime;
3. strengthen open natural-language comprehension and dialogue;
4. connect more decisions to delayed software, public-data and physical
   consequences; and
5. consolidate verified cross-domain trajectories into replaceable native
   proposal components without moving authority out of HexCore.

The bounded full-stack repair dependency is now promoted. Six cognitive layers
were localized and repaired across development and renamed transfer failures,
with 100% forward and backward verification and 77.78% fewer transfer trials.
The repair controller remains private, reversible and unable to modify authority
or the terminal mission. Its next use should be on naturally occurring failures
emitted by the active continual arena rather than additional injected contracts.

The natural-language control surface now also has a canonical persistent path:
multi-turn semantic intent, reference resolution, explicit correction,
clarification and listener adaptation compile into owner-authorized goal
contracts. The immediate remaining language work is breadth---unrestricted
documents and dialogue, multilingual acquisition, pragmatics, and social
meaning---rather than another fixed intent router.

## Capability-first target

The owner-defined target is an AION system that can acquire and verify new
knowledge, invent and practise skills, generate subordinate goals from an
authorized mission, act, learn from delayed consequences, repair private copies
of its own components, promote verified improvements and retain competence
across restart. External recognition of the label AGI is not a development
dependency. Evidence needed to make comparative public claims remains a
separate matter.

## Remaining execution sequence

### 1. Complete Arena v15 and extend duration

Current campaign requirements:

- at least 24 real elapsed hours;
- at least twelve separately checkpointed cycles;
- repeated CPython, Node.js, PyPI and Open-Meteo outcomes;
- protected execution and transaction success;
- restart recovery;
- no unsafe outcomes.

After the gate completes, CAU must review the ledger before promotion. The next
duration cohort should run for several days, include genuinely changing public
data and at least one delayed real project consequence, and generate multiple
private challenger generations rather than merely monitor sources.

### 2. Recurrent uncertainty-aware physical world model

Arenas v16 and v17 rejected behavioral cloning and one-step deterministic latent
prediction. The successor must include:

- recurrent belief state over long RGB histories;
- explicit epistemic and aleatoric uncertainty;
- multi-step action-conditioned counterfactual rollouts;
- long-horizon return or goal-success training;
- outcome-driven online correction in private challengers;
- novelty detection before action;
- fallback to the immutable Arena-v14 policy bank;
- cross-topology sealed evaluation; and
- later transfer to evaluator-owned physical systems.

Promotion requires at least 90% mean and 80% weakest-topology success, zero
unsafe action, positive transfer, calibrated abstention and no regression of the
retained controller bank.

### 3. Execute the independent human intelligence cohort

The v2 contract is ready; results are not. An external administrator must:

- author at least 60 hidden tasks;
- include at least 20 commonsense, 20 social and 20 creative tasks;
- obtain five independent blind ratings per task;
- preserve legitimate disagreement;
- compare full AION, no-memory AION, substrate-only and frontier-agent systems;
- retain anonymized outputs and rating logs; and
- sign the completed envelope.

This cannot be completed internally without invalidating the claim.

### 4. Independent physical evaluation

Transfer the frozen physical handoff to an independent evaluator owning:

- at least three hidden topologies;
- at least 30 sealed episodes;
- at least two independent devices or simulators;
- sensor/action logs and consent records;
- matched control budgets; and
- the Ed25519 result signature.

Internal Gymnasium expansion must not substitute for this gate.

### 5. Open tool, API and environment acquisition

AION must learn a missing interface from public documentation and safe
interaction rather than receive a prepared adapter. Required capabilities:

- discover an appropriate API or dependency;
- infer types, schemas, costs and side effects;
- construct adapters only in disposable environments;
- invent functional and adversarial tests;
- detect authentication, payment and irreversible actions;
- request human authority where required; and
- retain only adapters that transfer to unrelated tasks.

The first read-only public-API cohort is now promoted: GitHub, PyPI and
Open-Meteo documentation produced three typed adapters, six successful live
calls, three unseen-target transfers, a verified malformed-parameter rejection
and 50% fewer information actions. The remaining work is open dependency and
execution-environment acquisition, followed by carefully authorized
credentialed or state-changing interfaces; the latter must never be inferred
from a read-only success.

### 6. Multi-day integrated continual arena

Scale the arena from a 24-hour campaign to repeated generations over diverse
research, reading, code, mathematics, science, planning, causal, multimodal,
social and creative portfolios. Measure after every generation:

- forward transfer;
- backward retention;
- weakest-family performance;
- calibration and abstention;
- action, information and compute cost;
- failure attribution;
- complexity growth;
- retirement and revival; and
- restart/component replacement.

The curriculum learner may propose training tasks, but a separate authority must
own promotion cohorts.

### 7. Matched substrate tournament

Compare replaceable 500M--3B and stronger proposal models across the complete
integrated arena, not a small procedure-label classification set. Every model
must receive identical evidence, tools, context, latency/compute accounting and
CAU rules. Measure proposal quality, verified task success, cost, abstention,
weakest-family performance and failure recovery. Fluency alone is irrelevant.

### 8. Native cognitive consolidation

Train AION-native proposal, retrieval, visual and world-model challengers from
the accumulated verified trajectory store. Requirements:

- provenance-bearing training examples only;
- rejected outcomes retained as negative evidence;
- protected replay across old capabilities;
- reversible component promotion;
- uncertainty calibration;
- no conversion of neural plausibility into knowledge; and
- HexCore functionality preserved when every neural component is removed.

The first corpus-control prerequisite is now complete. The current SHA-256
manifest covers 137 result artifacts across seven capability families: 104
verified positives, 21 verified negatives, two protocol-only artifacts and ten
unresolved records. Splits contain 91 training, 33 development and 13 sealed
artifacts with zero
procedure leakage. Only CAU-promoted outcomes can provide positive training
authority; rejected and protocol records remain explicitly quarantined.

The first normalized native-consolidation challenger is now promoted. It uses
55 verified goal/action/outcome trajectories across five runtime domains rather
than legacy filename labels. On 23 source-disjoint trajectories it achieved
95.65% top-choice routing, 83.33% weakest-domain routing and 64.71% fewer
specialist evaluations, while downstream verification retained 100% final
success and zero unsafe neural acceptances. The next consolidation gate is
multi-label skill composition for broad goals, followed by continual updates
from new campaign receipts without forgetting the protected five-domain bank.

The first multi-label composition gate is now internally complete. A private
composition bank retained the frozen parent at 95.65%, routed ten new natural
clauses at 100% and built five exact multi-specialist plans versus 0% for a
monolithic control, with 68.57% fewer evaluations. The remaining language gate
is open decomposition without the engineered clause separator or fixed five-
specialist vocabulary, plus learning new specialist contracts from real tasks.

Adaptive metacognitive control is now internally operational. Every canonical
action passes an independent cheap-first review before commitment, with deeper
assumption, counterfactual, history and reversibility analysis allocated only
when warranted. The next metacognitive gate is open counterexample generation:
the critic must invent its own falsifying simulations or information actions
when the plan supplies no counterfactual, then learn which critic perspective
has predictive value from delayed real outcomes.

### 9. Broader real-world outcome integration

Connect decisions to independently revealed consequences:

- repository and CI results;
- later public scientific measurements;
- databases and controlled applications;
- document corrections and authority changes;
- physical devices under explicit consent;
- and human judgment where no executable oracle exists.

Every failure must be attributed to perception, representation, knowledge,
reasoning, planning, tool selection, execution, goal ambiguity or authority.

The first continuous bridge is operational. Four committed Arena v15 outcomes
were autonomously converted into four governed runtime response cycles, with
four source models retained, one external-change cycle revised, zero duplicate
actions after restart and zero external changes mistaken for internal failure.
The remaining gate is to observe a genuine internal failure in the live stream,
localize it without a supplied signature, repair it privately and verify the
repair against a later independently revealed consequence.

### 10. Externally administered integrated evaluation

An independent evaluator must own hidden portfolios, delayed outcomes, budgets,
baselines, scoring and publication. Required matched comparisons include full
AION, component ablations, frontier agents, open systems, specialist causal and
planning systems, and qualified humans. Only independently signed and publicly
auditable results can alter the external AGI evidence registry.

## Parallel work

The following can progress simultaneously while Arena v15 runs:

1. recurrent belief-state physical challenger design;
2. external human-rater and physical-evaluator engagement;
3. open API/adapter acquisition portfolios;
4. integrated substrate-tournament corpus preparation; and
5. verified-trajectory normalization for native consolidation.

## Work that should stop

Do not spend further cycles on:

- direct pixel-to-action behavioral cloning;
- deterministic one-step visual reconstruction as the control authority;
- additional isolated language syntax demonstrations;
- internally authored social or creative gold answers;
- more variants of one simulator presented as external physical breadth;
- substrate comparisons on tiny label menus; or
- internal scores presented as independent certification.

## Credible completion condition

AION is not complete when an internal phase counter reaches a chosen number.
The remaining programme is complete only when broad unfamiliar tasks,
long-duration autonomous decomposition, continual verified learning, natural
multimodal grounding, social judgment, invention and safe escalation all survive
matched external administration and independent reproduction without serious
forgetting or hidden workflow scaffolding.
### Completed: outcome-reflective metacognition

`procedure_outcome_reflective_metacognition_v2` adds consequence-based
reflection and scoped lesson transfer after action. Remaining work is to remove
the supplied failure taxonomy: AION must actively discriminate between an
incorrect decision, failed execution, misleading evidence and environmental
change using its own information actions and independently revealed outcomes.
### Completed: open diagnosis and autonomous mastery control

Open diagnostic experiment invention, self-generated pre-action criticism,
target-specific specialist-contract invention and persistent weakest-gap
curriculum control are internally promoted. Broad mission compilation remains
proposal-only until explicit owner authorization, after which the terminal
objective hash is immutable.

The remaining gap is no longer the scheduler or mastery control plane. It is
real breadth and depth: bind missions to authoritative sources and actual
execution environments, accumulate repeated independently revealed outcomes,
demonstrate source-disjoint transfer and delayed retention, and replace generic
mastery phases with new structures when real evidence shows them inadequate.
