\section{Open Causal Scientific Learning}
\label{sec:open-causal-scientific-learning}

\subsection{Integrated Objective}

This programme advances three connected capabilities: open vector-valued
causal theory construction, continuous world-model maintenance, and
outcome-led autonomous curriculum selection. The operational chain is
\[
\begin{aligned}
\text{observations}
&\rightarrow \text{sparse Photon theory}
\rightarrow \text{randomized intervention}\\
&\rightarrow \text{confounder rejection}
\rightarrow \text{causal theory}\\
&\rightarrow \text{failure diagnosis}
\rightarrow \text{revision or abstention}\\
&\rightarrow \text{outcome-led curriculum}
\rightarrow \text{retained improvement}.
\end{aligned}
\]

\subsection{Variable-Cardinality Vector Theory Construction}

Each sealed world contains four to six observed variables, two or three
outcomes, irregular timestamps, nuisance variables, and an unknown number of
latent continuous processes. AION is not supplied the relevant-variable set,
causal graph, latent count, or expression depth.

For each outcome, it grows and prunes a sparse Photon expression using raw,
quadratic, saturation, continuous-delay, latent-state, and interaction terms.
The search is bounded at six terms in this experiment. Selection optimizes
worst-regime held-out prediction plus description length.

\subsection{Observation Versus Intervention}

The benchmark deliberately supplies a non-causal proxy that is more accurate
than the true cause under observation:
\[
x_0=c+\epsilon_0,\qquad
x_1=c+\epsilon_1,\qquad
\operatorname{Var}(\epsilon_1)\ll\operatorname{Var}(\epsilon_0).
\]
The observational control therefore selected \(x_1\) as a false cause in
100\% of sealed worlds. Randomized interventions showed that manipulating
\(x_1\) did not change the outcome, while manipulating \(x_0\) did. The
intervention-aware learner rejected the false causal edge in 100\% of worlds.

\subsection{Continuous Theory Maintenance}

Twenty-five source-disjoint streams represented coefficient change, topology
change, sensor fault, execution anomaly, and an unexplained model family. AION
compared residual persistence, input shifts, anomaly density, same-topology
refits, alternative-topology refits, and predictive piecewise error.

Failure diagnosis was 100\%, mean durable change-point error was zero events,
and no temporary sensor or execution fault caused durable theory revision.
Every unexplained-family stream caused abstention.

An independently executed software process changed a saturating coefficient
from \(1.10\) to \(1.55\) at hidden event 160. AION detected event 160 exactly,
diagnosed coefficient change, and achieved \(R^2=1.0\) after revision.

\subsection{Outcome-Led Curriculum and Persistence}

Three curricula were selected from measured weaknesses: confounder rejection,
vector topology and latent-count discovery, and continuous failure diagnosis.
All passed while protecting earlier capabilities. Causal theories,
intervention records, revisions, curricula, software evidence, and the champion
survived restart with zero relearning.

\subsection{Verification and Claim Boundary}

Focused regression tested the parent compositional capability and the new
causal-science capability; both passed in 71.85 seconds. The complete historical
replay was deliberately deferred.

Variable columns, intervention labels, primitive features, the six-term ceiling,
failure taxonomy, generators, and evaluator remain engineered. The software
trace is independently executed but development-authored. This is bounded
causal scientific learning, not unrestricted science or AGI.

\subsection{Next Frontier}

The next stage must infer interventions from real software and project events,
propose sandboxed changes as experiments, learn from independent tests and
delayed outcomes, maintain competing project theories over long durations, and
use its outcome ledger to invent tools, experiments, and curricula for
human-authored external tasks.
