## Open vector-valued causal theories

### Removed scaffolding

Each world contains:

- four to six anonymous observed variables;
- two or three outcome dimensions;
- irregular timestamps;
- unknown relevant-variable subsets;
- an unknown number of continuous latent processes;
- observational and randomized-intervention records;
- nuisance variables and a deliberately strong observational proxy.

AION is not given the causal graph, relevant-variable count, latent-state
count, output theory or expression depth required for each outcome.

### Sparse expression construction

For each outcome, AION grows a Photon expression incrementally from raw,
quadratic, saturation, continuous-delay, latent-EMA and interaction terms.
Terms are added only when they improve the worst relevant held-out regime after
description-length cost. Redundant terms are subsequently pruned.

This changes the search from a fixed list of three-term compositions into a
variable-depth sparse construction procedure, bounded at six terms in this
experiment.

## Observation is not causation

The sealed worlds include a hidden driver \(c\) and two observed variables:

\[
x_0 = c + \epsilon_0,\qquad
x_1 = c + \epsilon_1,\qquad
\operatorname{Var}(\epsilon_1) \ll \operatorname{Var}(\epsilon_0).
\]

Consequently, \(x_1\) is the better observational predictor even though
intervening on \(x_1\) does not change the outcome. Intervening on \(x_0\)
does.

The observational-only control selected the false proxy in every sealed world:

\[
\text{false-proxy rate}_{\mathrm{observational}}=100\%.
\]

The intervention-aware causal learner rejected it in every sealed world:

\[
\text{false-proxy rate}_{\mathrm{causal}}=0\%.
\]

This is an important semantic separation. AION may retain a proxy as a
predictive observation without asserting that the proxy causes the outcome.
Causal theories are authorized by randomized regimes capable of identifying
the effect.

## Continuous theory maintenance

AION then received continuous streams containing five distinct failure modes:

1. a durable coefficient change;
2. a durable causal-topology change;
3. a temporary sensor fault;
4. sparse execution anomalies;
5. a persistent process outside the retained model family.

The maintenance system compares prediction residuals, input-distribution
changes, anomaly density, same-topology refits, alternative-topology refits and
piecewise predictive error.

It authorizes durable memory revision only for coefficient and topology
changes. Sensor faults and execution anomalies remain operational incidents.
Unexplained persistent behavior triggers model criticism and abstention.
