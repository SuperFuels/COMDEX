# AION Autonomous Executor-Contract Campaign

## Promotion

The internally evaluated procedure
`procedure_autonomous_executor_contract_campaign_v1` is promoted. It is the
first multi-generation campaign in which the Autonomous General Apprentice
encountered missing executors, acquired compatible operational contracts from
verified methods, submitted them to fresh outcome authorities, and retained
only contracts backed by verified receipts.

## Trigger

The campaign was not opened from a manually numbered phase. Arena v15 produced
a later public consequence after AION's precommitment cursor. The prediction
was scored, Generation 3 closed, and the weakness-driven curriculum emitted a
new Cargo task with `requires_executor_invention=true`. No retained executor
matched that gate and authority.

## Operating loop

```text
weakness-driven curriculum task
  -> discover that no retained executor applies
  -> select a compatible installed outcome authority
  -> reconstruct a prior verified method
  -> create a proposal-only executor contract
  -> execute fresh public, hidden, transfer and retention gates
  -> receive a verified outcome receipt
  -> register the executor contract
  -> close the generation
  -> prefer a novel compatible authority
  -> repeat
```

Registration is impossible before receipt verification. Memory artifacts may
propose methods, but they are explicitly prohibited from serving as independent
outcome authorities.

## Failure-driven corrections

Two rejected episodes materially improved the control plane.

First, the Cargo outcome passed all four projects and hidden authorities, but
the campaign wrapper looked for a restart field that the parent procedure
stores under its promotion gate. The task was rejected. AION corrected the
integration attribution and replayed the same failed task rather than skipping
it or weakening retention.

Second, the curriculum briefly selected the retained artifact store as the
authority for physical/social grounding. That contract was invalid: retained
memory cannot independently reveal a new consequence. The task was closed as a
rejected contract without fabricating an outcome. Authority discovery and task
selection were corrected so only independently revealing authorities can
satisfy an apprenticeship contract.

After promotion, the curriculum selected physical/social grounding as the next
closed-loop gap and chose the Arena v15 public delayed-outcome ledger. AION

## Claim boundary

This is a substantial advance in autonomous executor acquisition, not arbitrary
subject mastery. Cargo, Node and SQLite are distinct execution authorities and
their transfer families exercise different structures, but all three remain
computational. Safe runner adapters, authority-specific verification harnesses
and the executor meta-contract remain engineered.

The next decisive advance is to acquire executor contracts whose authorities
are not compilers or databases: delayed public scientific observations,
unfamiliar natural documents, natural multimodal evidence, and eventually
human outcomes with legitimate disagreement. Those contracts must pass the same
receipt-before-registration, transfer, retention and fail-closed rules.
