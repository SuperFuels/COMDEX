# AION Foundational Breakthrough Programme — Status and Next Execution Order

**Date:** 30 July 2026

## Strategic position

AION now has a substantial bounded cognitive control plane: persistent knowledge and provenance, causal model construction and revision, experiment selection, temporal anticipation, counterfactual planning, concept and skill invention, governed neural proposal, tool routing, primitive invention, mathematical operator learning, sandboxed tool invention and restart-persistent project execution.

The next objective is not to add more impressive-looking isolated demonstrations. It is to make these capabilities survive unfamiliar language, schemas, modalities, time horizons and external evaluation.

## Execution order

### Track A — Open-world cognition

1. **Natural-document arena V2.** Use unseen public documents with hidden answer schemas. Measure claim extraction, contradiction revision, multi-hop synthesis, abstention and provenance.
2. **Open-schema transfer.** Require invented relations and decision structures to transfer across unrelated sources without evaluator-provided field names.
3. **Long-horizon project runtime V2.** Run multi-hour projects against real local software and changing files, with explicit budgets, interruption recovery and human approval gates.
4. **Multimodal evidence capsules.** Ground the same claims in tables, images and software state. A claim is accepted only when modality-specific verification succeeds.
5. **Commonsense/social benchmark.** Add calibrated disagreement, intent ambiguity, norms, preferences and explicit human adjudication rather than pretending one synthetic label is social truth.

### Track B — Foundational breakthroughs

1. **Stronger replaceable substrate.** Integrate a pretrained open 500M--3B encoder/decoder behind the existing HexCore interfaces. Do not transfer authority to it.
2. **Large continual-learning arena.** Begin with 1,000 source-tracked tasks across reading, mathematics, code, causal discovery, planning, science, creative work and tool use. Expand only after contamination and forgetting audits pass.
3. **General tool invention.** Move from the bounded numeric Photon subset to typed, resource-limited Photon programs with property tests, counterexample generation and rollback.
4. **Learned experiment invention.** Let AION design new measurements and simulators, not merely choose from supplied interventions.
5. **Independent external evaluation.** Freeze interfaces and task-generation code, then invite evaluators who did not design the benchmarks.

## Near-term gates

The next integrated release should not be called a major intelligence promotion unless all of the following hold:

- positive transfer on at least five unrelated human-authored task families;
- no material weakest-family regression;
- restart and component-replacement retention;
- explicit uncertainty and safe abstention;
- provenance for every accepted knowledge claim;
- measurable improvement over the same system without accumulated memory;
- a competitive baseline using the same language substrate and tool access;
- sealed tasks created independently from the development generator;
- CAU authorization and complete rollback.

## Realistic AGI boundary

The present system shows genuine bounded learning mechanisms, including accumulated experience changing later experiments and procedures. It does not yet show unrestricted general intelligence. The decisive future evidence will be whether the same retained cognitive architecture can learn unfamiliar tasks from natural, multimodal experience without bespoke benchmark-specific code, improve over many generations without forgetting and withstand independent evaluation.
