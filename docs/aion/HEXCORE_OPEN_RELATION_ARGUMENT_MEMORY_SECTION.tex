\section{Open Relation and Argument Memory}
\label{sec:open-relation-argument-memory}

AION completed a bounded open-schema learning cycle without a supplied concept
list, relation vocabulary, character inventory or argument schema.  A
replaceable proposal substrate invented concepts, predicates and argument
structures from book evidence.  HexCore retained a structure only when its
quotation was recoverable from the immutable source:
\[
\begin{aligned}
 \text{evidence}
 &\rightarrow \text{open schema proposal}
 \rightarrow \text{span and endpoint grounding}\\
 &\rightarrow \text{persistent ontology}
 \rightarrow \text{delayed memory use}.
\end{aligned}
\]

An initial open induction produced a fragmented ontology in which nearly every
relation had a distinct predicate.  A governed consolidation pass merged only
compatible predicates, reducing 45 predicate types to 35 while preserving
every original predicate, concrete relation, quotation and original-to-canonical
mapping.  This adds abstraction after invention without erasing provenance.

After runtime reconstruction, AION answered twelve delayed questions using
retained semantic memory only.  Book files were not reread.  All literary
arguments remained marked as \texttt{reported\_argument}; none was promoted to
independently verified truth.

The promoted procedure is
\texttt{procedure\_open\_relation\_argument\_memory\_189258f3d567}.
The result remains bounded because evidence sampling, provider selection,
question construction and acceptance checks remain development controlled.
