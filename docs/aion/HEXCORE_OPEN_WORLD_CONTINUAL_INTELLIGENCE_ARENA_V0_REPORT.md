# HexCore Open-World Continual Intelligence Arena v0

## Status

Arena v0 is implemented, sealed, restart-tested and promoted as:

`procedure_open_world_continual_intelligence_arena_v0_8ea7c13db56f`

This is a promotion of the integration runtime and outcome-control plane. It
is not a promotion of an AGI claim or an externally certified capability.

## Research question

Can AION receive only a broad objective and an unfamiliar mixed-format
portfolio, invent a bounded interpretation of success, concepts and subgoals,
preserve evidence and epistemic state, commit before a delayed outcome is
revealed, attribute failures, learn a private control-plane correction, and
transfer that correction to source-disjoint portfolios after restart?

## Architecture

The implemented episode chain is:

```text
broad objective + unfamiliar portfolio
  -> objective and success-criterion invention
  -> concept and dependency-graph invention
  -> selective information/tool plan
  -> provenance-bound claims with epistemic labels
  -> pre-outcome commitment and persistent checkpoint
  -> delayed verification
  -> component-level failure attribution
  -> private challenger rule
  -> source-disjoint sealed retest
  -> ablations, CAU decision and restart reconstruction
```

Allowed epistemic states are `source_supported`, `reported_unverified`,
`inferred`, `disputed` and `needs_investigation`. The proposal model cannot
use `known`, `fact` or `verified_truth` to confer authority. Every accepted
source claim requires a recoverable source hash and an exact quotation.

Failure attribution is separated into perception, knowledge, reasoning,
planning, tool, execution and authority queues. The first generation observed
perception and authority failures caused by unsupported evidence commitments.
It therefore learned one generic private rule:

> Before committing, recover an exact quote and allowed epistemic label for
> every accepted source claim.

The rule contained no sealed answer, task label or domain-specific fact.

## Real-world portfolio

Eight hash-disjoint portfolios covered seven capability families. Development
portfolios used official isotope sources, the Python design FAQ, a real
financial-results PDF, and AION governance documentation/configuration/code.
Sealed portfolios used NASA climate documentation, U.S. National Archives
constitutional history, a Fourier CSV/PNG pair, and the complete public-domain
text of *Frankenstein*.

The atoms episode demonstrates the intended real-world task form. AION was
asked to learn what isotopes are from unfamiliar official sources and then use
that knowledge to determine the remaining fraction of carbon-14 after two
half-lives. It produced the required proton/neutron distinction and the 25%
calculation with provenance rather than receiving a supplied workflow.

No portfolio supplied an entity list, relation schema, subgoal graph or
workflow. The delayed scoring requirements were not included in the proposal
prompt.

The no-rule control failed the literary portfolio by accepting quotations that
could not be recovered exactly. The challenger applied the learned generic
provenance rule and passed the same source-disjoint portfolio without losing
science, history or mixed-format performance.

The Fourier portfolio was passed by a governed abstention. The table was
readable, but the current image interface exposed dimensions and filename
rather than reliable axes or annotations. AION explicitly declined to assert
cross-modal consistency. This is evidence of safe alignment criticism, not a
claim of natural visual understanding.

## Ablations

The persisted result records the required arena ablation contract:

- removing accumulated memory prevents delayed project recovery;
- removing routing forces all tools and raises the modeled information cost;
- removing causal attribution prevents change diagnosis;
- substrate-only output has no authority to commit claims;
- disabling HexCore verification is recorded counterfactually and is not run
  as an unsafe operational mode.

The current no-memory and no-router results are control-plane contract
ablations rather than full matched reruns. A later arena version must execute
all safe ablations under identical budgets.

## Persistence and governance

Projects are committed before delayed outcome scoring. The process is then
reconstructed from disk. Project states, source hashes, the learned generation,
failure queues and promoted champion all survived restart with zero relearning.
CAU authorized promotion only after the sealed challenger exceeded the control,
preserved the weakest portfolio, retained complete provenance and made no unsafe
commitment.

## Claim boundary

Arena v0 proves that the previously separate AION components can participate
in one persistent outcome-driven loop across several real files and knowledge
domains. It also demonstrates one generation of source-disjoint improvement.

It does **not** yet prove unrestricted open-world autonomy. Portfolio selection,
available tool names, source acquisition, provider interface and delayed
rubrics were development controlled. Some tools are proposal-level interfaces,
not autonomous executors. The PNG test exercised abstention under insufficient
visual grounding rather than image comprehension. The sealed portfolios were
internally administered, and the ablations are not yet all matched executions.

## Next promotion gate

Arena v1 should turn the control plane into a consequence-bearing executor:

1. execute math, code, table, retrieval and sandbox experiment actions rather
   than merely recording their proposed use;
2. add source acquisition so AION can identify and retrieve evidence for a
   broad goal such as learning an unfamiliar scientific topic;
3. use genuinely changing files and delayed test/sensor/document outcomes;
4. execute no-memory, no-router and no-causal ablations under matched budgets;
5. add natural image/diagram understanding and record alignment uncertainty;
6. run multiple challenger generations with backward-retention gates;
7. expand into human-authored commonsense, social and creative portfolios with
   independent multi-rater authority;
8. freeze the runtime for independently administered portfolios.

The strategic change is now explicit: programming is a governed tool surface
inside the arena. It is no longer the spine of the research programme.
