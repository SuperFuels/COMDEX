# AION Guided Foundation Academy and Intelligence Glyph Consolidation

## Strategic correction

AION no longer treats every unassessed subject as an equally urgent next lesson.
The broad social, biology and chemistry curricula remain retained, but they are
parked while a depth-first Programming, Systems and Security Academy supplies
the primary apprenticeship path.

Promoted control planes:

- `procedure_guided_programming_systems_security_academy_v1`
- `procedure_governed_intelligence_glyph_consolidation_v1`
- `procedure_accelerated_algorithms_data_structures_apprenticeship_v1`

## Programming, Systems and Security Academy

The academy contains thirteen prerequisite-bound modules:

1. Python Core;
2. Algorithms and Data Structures;
3. Advanced Python;
4. Testing and Debugging;
5. Software Engineering;
6. Database Engineering;
7. Operating Systems;
8. Networking;
9. Rust Systems Engineering;
10. Secure Software Engineering;
11. Distributed Systems;
12. Architecture and Production Operations; and
13. an Integrated Engineering Capstone.

The runtime allocation is 70% primary academy, 20% retention/remediation and
10% cross-domain transfer. Unrelated breadth exploration is parked until the
academy capstone completes. The owner supplies the strategic academy and
competency graph; AION retains responsibility for selecting practice,
diagnosing failure, requesting teaching, escalating difficulty and learning
from outcomes.

Python Core was imported as an operationally bounded certificate. Algorithms
and Data Structures then became the first unlocked module. Software Engineering
remains locked until Algorithms, Advanced Python and Testing/Debugging are all
verified.

## First accelerated module

The Algorithms and Data Structures module used six curated concept capsules:
complexity, binary search, breadth-first search, weighted shortest paths,
topological ordering and dynamic programming. This removed open-web search
overhead while leaving competence under executable authority.

The first implementation passed public practice but accepted a negative-weight
graph in Dijkstra's algorithm. The sealed examiner rejected it. AION attributed
the failure to the non-negative-edge precondition, applied narrow remediation
and passed a fresh sealed test. It then passed 120 generated property cases,
transferred topological ordering into an unfamiliar project dependency problem,
passed security screening and reconstructed after restart.

## Governed intelligence glyphs

The consolidation layer distinguishes four storage roles:

1. immutable evidence remains in its original provenance ledger;
2. verified concepts become deduplicated Knowledge glyphs;
3. verified procedures become proposal-only Skill glyphs;
4. uncompleted academy material becomes Curriculum glyphs marked
   `proposed_not_learned`.

Each glyph carries content-addressed evidence identifiers rather than another
copy of the source text. Evidence is loaded only on demand and its SHA-256 hash
must still match. A compact structured representation is stored as a
gzip-compressed packet while retaining Tessaris/GlyphOS-compatible renderings,
for example:

```text
⟦ Knowledge | dijkstra_nonnegative_precondition : g_<content-id> -> Verify ⟧
```

The test suite also altered the compressed packet and confirmed that loading
fails closed on checksum mismatch.

## Live status and boundary

The background curriculum service now executes the academy first, keeps broad
curricula parked, and rebuilds the glyph store only when verified source
artifacts change. Sixteen focused tests pass.

This is accelerated bounded learning, not a Matrix-style instant transfer of
expertise. Curated capsules dramatically reduce discovery cost, but executable
practice, sealed counterexamples, transfer and delayed retention still decide
competence. The academy graph and first module are engineered. Advanced Python,
Testing/Debugging and all later systems/security modules remain incomplete.
