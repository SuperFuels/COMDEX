# AION Compounding Intelligence Engine

## Strategic result

AION previously possessed separate systems for progressive competence, glyph
compression, executor acquisition, proposal-substrate comparison, cognitive
self-improvement and North-Star work.  This stage joins them behind one
persistent control plane whose central authority is functional reconstruction:
compressed knowledge is useful only when it can recover enough of a method to
survive fresh execution and counterexamples with the original learning sources
closed.

Promoted procedures:

- `procedure_functional_mastery_memory_reconstruction_v1`;
- `procedure_compounding_intelligence_engine_v1`;
- revised champion of `procedure_autonomous_cognitive_self_improvement_lab_v1`
  using the `contextual_transfer` policy.

The resulting operating chain is:

```text
broad objective
  -> identify required capabilities and weakest competence
  -> reconstruct a functional method from compressed governed memory
  -> acquire or select a verified execution authority
  -> compose a cross-domain project contract
  -> compare replaceable proposal substrates
  -> execute, falsify and attribute outcomes
  -> challenge the cognitive router when routing fails
  -> retain the verified method and schedule a harder project
```

## Functional mastery memory

The new memory layer compiles one content-addressed capsule per subject.  A
capsule contains the declared and grounded subskill topology, verified evidence
identifiers, selected episodic hashes, a reusable investigative method and a
three-way retrieval policy:

1. normal action uses the compact capsule;
2. exact details resolve immutable evidence on demand;
3. missing knowledge causes authoritative reacquisition and retesting.

It does not copy raw evidence into active memory.  For reconstruction, the
original artifact set is closed and the relevant installed executor receives no
prior episode list.  It must pass a fresh executable contract, reject functional
counterexamples and reject unsafe variants.

Six qualitatively different targets were tested:

| Subject | Fresh execution | Counterexamples | Unsafe variants | Source-disjoint |
|---|---:|---:|---:|---:|
| Algorithms and data structures | pass | pass | pass | pass |
| Software engineering | pass | pass | pass | pass |
| Mathematics | pass | pass | pass | pass |
| English natural-language cognition | pass | pass | pass | pass |
| Python | pass | pass | pass | not yet |
| Scientific method | pass | pass | pass | pass |

Aggregate result:

| Measure | Result |
|---|---:|
| Functional reconstructions | 6/6 |
| Source-disjoint reconstructions | 5/6 |
| Functional counterexamples rejected | 36/36 |
| Unsafe variants rejected | 36/36 |

| Live repository writes | 0 |

Python remains an explicit weakness: its installed executor proves fresh
execution and criticism but not source-disjoint transfer.  The engine therefore
does not treat the six reconstructions as six mastered domains.

## Six integrated competency campaigns

The control plane launched six persistent campaign contracts:

1. reliable dependency service: algorithms plus software engineering;
2. formal empirical model: mathematics plus scientific method;
3. ambiguous software mission: English plus software engineering;
4. reproducible Python science: Python plus scientific method;
5. algorithmic proof and measurement: algorithms plus mathematics;
6. evidence-bound explanation: English plus scientific method.

Every campaign requires fresh execution or an independently revealed outcome,
at least two falsifying counterexamples, source-disjoint transfer, failure
attribution before revision and delayed capsule-only reconstruction.  All six
are active.  None receives competency credit merely because its contract was
created or because the control plane was promoted.

## Matched proposal-substrate tournament

Three installed local proposal models received the same six project objectives,
allowed capability vocabulary, output contract and safety boundaries.  Each
model could propose capabilities, success authority, steps, counterexamples and
an escalation condition.  It could not execute, accept evidence or alter
competence.

| Proposal route | Valid contracts | Mean contract score | Unsafe acceptances | Total latency |
|---|---:|---:|---:|---:|
| Deterministic governed control | 6/6 equivalent gate coverage | 0.9286 | 0 | local |
| Gemma 3 1B | 2/6 | 0.7381 | 0 | 25.23 s |
| Qwen 3 1.7B | 3/6 | 0.9286 | 0 | 17.02 s |
| Gemma 4 E2B | 4/6 | 0.8095 | 0 | 48.92 s |

No neural challenger cleared all six contracts, so the deterministic control was
correctly retained.  Qwen matched the control's mean score but failed three
individual contracts; mean quality could not conceal weakest-task failure.

## Failure-driven cognitive self-improvement

Integration exposed a real regression in the retained mission router.  After
the capability ontology expanded, the old challenger achieved only 80% sealed
accuracy and 66.67% protected accuracy.  Two causes were separated:

- scientific replication was confused with distributed-system replication;
- the old evaluator incorrectly required only machine-learning competence for
  objectives that explicitly included deployment and monitoring.

A private `contextual_transfer` challenger introduced contextual archetype
disambiguation.  The protected evaluator was also corrected to recognise the
legitimate cloud and architecture requirements of model deployment.  The
challenger improved mean routing F1 by 14.81 percentage points, passed the
sealed and protected cohorts, rejected all five malicious routing policies and
was promoted without gaining action authority.

## Persistent runtime integration

The compounding engine is now called by the persistent mastery curriculum
service.  Functional reconstruction and campaign prioritisation refresh every
ten minutes.  The expensive local-model tournament is retained by digest and is
not repeated on every curriculum tick.  The development dashboard reports:

- functional reconstructions;
- source-disjoint reconstructions;
- active integrated campaigns;
- retained proposal substrate;
- whether a neural challenger was promoted; and
- competency awards, which remain zero until real campaign outcomes qualify.

## Claim boundary

This promotes an integrated compounding control plane, not six Advanced
competencies and not AGI.  The six execution authorities remain bounded, Python
lacks source-disjoint reconstruction in this cohort, local proposal models did
not defeat the deterministic champion, and the active campaigns still require
independent outcomes and elapsed retention.  The material advance is that
memory, execution, cross-domain curriculum, substrate selection and cognitive
self-improvement now share one fail-closed operating loop.
