# AION Roadmap Reconciliation after Arena v14

The attached roadmap is not mostly outstanding. Its current status is:

| Path | Status | Principal remaining gate |
|---|---|---|
| A — Experimental/software | Strong bounded; programming internally closed | Independent hidden administration and delayed human review |
| B — Knowledge/concepts/memory | Strong bounded | Larger arbitrary corpora, matched retrieval controls and independent questions |
| C1 — Multimodal/physical | Advanced bounded plus real local physical outcomes | Independent devices, broader natural media and evaluator ownership |
| C2 — Social/commonsense | External v2 contract frozen; capability remains a major gap | Evaluator-authored hidden cohort and independent multi-rater outcome |
| C3 — Creative synthesis | External v2 contract frozen; capability remains a major gap | Independent novelty/usefulness/consistency ratings |
| D1/D2 — Epistemics/falsification | Operational across the stack | Broader external pressure |
| D3 — Long continual arena | 24-hour real-outcome campaign active; not yet promotable | Finish elapsed-time gate, then extend to days and multiple generations |
| E — Substrates/consolidation | Continual physical bank operational; open-pixel imitation rejected | Predictive latent dynamics, then matched broader substrate tournament |
| F — Independent evaluation | Protocol complete; outcome blocked | Independent evaluator must run and sign |

Arena v13 changes C1 materially: AION now moves beyond prediction into a real
closed-loop physical project that invents and retains a tool only after measured
improvement. It does not close independent authority.

Arena v14 advances E: verified experience now consolidates sequentially into a
replaceable neural skill bank across three physical topologies without final
forgetting. A monolithic challenger was rejected, while private capacity kept
the protected floor intact. This does not close open representation learning or
independent authority.

Arena v16 then removed the explicit task identifier and hand-designed physical
state at inference. Visual task binding reached 99.89%, but behavioral cloning
failed the sealed control gate at 7/15 despite three correction generations.
The result is retained as a governed negative: the next neural architecture
must learn latent transition consequences rather than scale action imitation.

The highest-leverage internal sequence is now:

1. multi-hour/day continual projects with repeated real consequences;
2. integrated social, commonsense and creative portfolios with human raters;
3. open visual/task representation challengers above the private skill bank;
4. matched stronger-substrate tournament over the complete arena; and
5. native consolidation from the verified cross-domain trajectory store.

In parallel, the frozen external handoffs should be given to an independent
evaluator immediately. Further internal work cannot substitute for that step.
