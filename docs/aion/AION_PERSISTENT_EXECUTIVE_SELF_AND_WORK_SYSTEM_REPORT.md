# AION Persistent Executive Self and Executive Work Systems

## Result

AION now maintains a restart-persistent executive identity and selects a
situation-appropriate operating method before planning.  The promoted procedure
is:

`procedure_persistent_executive_self_and_work_system_v1`

The resulting control chain is:

```text
constitutional identity + authorized commitments
  -> inspect goals, signals, failures and capability gaps
  -> choose reactive, work or reflective attention
  -> select an appropriate work system
  -> compose reusable executive skill contracts
  -> plan through the canonical cognitive runtime
  -> metacognitive review
  -> governed action and outcome
  -> retrospective and retained method evidence
```

## Executive Skills Library

The library contains 16 reusable skills covering objective framing,
stakeholder/authority mapping, backlog invention, dependency and critical-path
analysis, value prioritisation, Scrum, Kanban, incident response, scientific
investigation, decision analysis, risk, quality, resource planning, progress
control, retrospective learning and handover.

These skills compose into seven operating systems:

1. product delivery;
2. research investigation;
3. operational incident response;
4. continuous operations;
5. strategic decision-making;
6. learning apprenticeship; and
7. bounded task execution.

Scrum is not a universal default.  It is selected for iterative product work;
incidents receive stabilise--diagnose--recover control, research receives
hypothesis/experiment control, and continuous queues receive Kanban flow.

## Persistent Executive Self

The executive state retains:

- constitutional identity and a content hash;
- stable values, derived motives and personality parameters;
- authorized commitments and immutable objective hashes;
- incoming signals and surprise;
- current strategic attention;
- reflection and strategy-question history; and
- parent-bound instrumental goal proposals.

It uses three cheap operating modes:

- **reactive:** an important or surprising consequence requires attention;
- **work:** an eligible authorized commitment can advance; and
- **reflective:** no work is immediately executable, so the system examines
  recurring failures, strategic stagnation, capability bottlenecks or missing
  owner authority.

Reflection is proposal-only.  It cannot silently create a terminal objective or
authorize an external action.  Self-preservation, authority acquisition,
unbounded resource acquisition and objective rewriting are explicitly rejected
as terminal drives.  Legitimate instrumental work remains possible only under
an immutable authorized parent commitment.

## Runtime integration

The canonical cognitive runtime now:

1. wakes the Executive Self before selecting or idling;
2. records strategic attention on every cycle;
3. composes an executive work system for every selected goal;
4. attaches the selected method and skill sequence to the plan;
5. preserves HexCore and metacognitive authority over execution;
6. records verified method/skill outcomes after completion; and
7. enters bounded reflective mode rather than becoming cognitively blank when
   no executable goal exists.

## Claim boundary

This is a persistent executive control process, not evidence of phenomenal
consciousness, subjective experience, human desire or unrestricted agency.  Its
personality is a stable operating perspective; its motives are bounded
attention policies; and its generated proposals remain subordinate to
authorized commitments and governed action.

The next major test is long-horizon portfolio ownership: AION should manage
several concurrent real projects, choose which deserves attention over time,
change operating methods when outcomes demand it, identify neglected strategic
work and demonstrate higher completion and lower owner intervention than a
goal-by-goal control.
