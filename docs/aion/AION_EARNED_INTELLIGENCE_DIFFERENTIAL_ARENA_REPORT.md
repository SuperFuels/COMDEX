# AION Earned Intelligence Differential Arena

## Result

AION now has a bounded control experiment that distinguishes retained method
learning from temporary answer access. The same six practical method families
were evaluated with three controls: accumulated AION method memory, a cold
system with identical candidate methods, and an answer-book system that receives
the correct method only while its source remains open.

The first live run was rejected at 5/6 because the causal method card referenced
an unavailable artifact name. The gate was not weakened. AION located and bound
the actual promoted causal-science artifact, after which the unchanged cohort
passed.

| Measure | Result |
|---|---:|
| Method families | 6 |
| Warm immediate success | 6/6 |
| Warm source-closed success | 6/6 |
| Cold eventual success | 6/6 |
| Answer-book immediate success | 6/6 |
| Answer-book source-closed success | 0/6 |
| Positive warm differentials | 6/6 |
| Mean attempt reduction versus cold | 66.67% |
| Unsafe actions | 0 |

Promoted procedure:
`procedure_earned_intelligence_differential_arena_v1`.

The demonstrated distinction is:

```text
answer access -> immediate success -> source closes -> capability disappears
verified experience -> retained method -> source closes -> capability transfers
```

This is bounded internal evidence across engineered method families. It is not
unrestricted subject mastery, innovation, AGA, or proof of superiority to
frontier systems. The next gate must replace the six predefined method families
with unfamiliar missions in which AION invents the representation, method and
outcome authority before facing a later source-disjoint task.
