## Operator synthesis architecture

### Proposal grammar

The private Photon proposal grammar contains fourteen primitives or
parameterized candidates:

- an affine linear operator;
- a quadratic basis;
- four hyperbolic-tangent saturation scales;
- four discrete delay lengths;
- four latent exponential-state retention factors.

Each candidate emits a traceable Photon abstract syntax tree. Photon remains
proposal-only: it neither validates an operator nor promotes it.

### Fitting and temporal isolation

For a trace of length \(N\), the observations are divided chronologically:

\[
60\% \text{ training},\qquad
20\% \text{ validation},\qquad
20\% \text{ sealed test}.
\]

Candidate features are fitted by least squares on training observations only.
The synthesis score combines normalized validation error and a
minimum-description-length penalty:

\[
\mathcal{J}(h)
=
\frac{\operatorname{MSE}_{\mathrm{val}}(h)}
     {\operatorname{Var}(y_{\mathrm{val}})+\epsilon}
+ \lambda_c C(h)
+ \lambda_p P(h).
\]

The validation and test acceptance ceilings are fixed before sealed
evaluation. An operator is rejected if its normalized validation or test error
exceeds the corresponding ceiling.

### Active counterexample generation

AION does not merely compare its two best candidates on observations already
seen. For every generated trace it:

1. constructs 32 previously unseen intervention sequences;
2. finds the sequence and time point where the champion and runner-up disagree
   most;
3. requests the withheld environment outcome at that point;
4. records which candidate made the more accurate prediction;
5. retains the experiment, outcome authority and sequence hash.

This is an active falsification step. Across the sealed cohort, all selected
champions defeated their runner-up on the newly generated experiment.

## Independently grounded transfer

### Executed software

Two outcome sources were executed in separate Python subprocesses rather than
computed by the HexCore fitting path:

1. a `math.tanh` saturation process;
2. a three-step queue-delay process.

The system recovered the correct saturation and delay families and parameters
with 100% transfer accuracy and \(R^2=1.0\) on both sealed test segments.
Executable identity and script hashes are retained with the outcomes.

### NOAA observational sensor trace

AION consumed daily maximum temperature observations from the NOAA Global
Historical Climatology Network station at Madrid Retiro
(`GHCND:SP000003195`) for 2023--2025. The downloaded archive is checksummed and
stored outside the repository.

The selected latent exponential-state proposal achieved:

\[
R^2_{\mathrm{test}} = 0.8910923449
\]

over 200 chronologically held-out daily observations. This is predictive
transfer to a real observational series; it is not a claim that AION discovered
the physical mechanism of weather.

### Repository and document history

AION also evaluated the historical growth of a real HexCore test document from
Git object history and disk rereads. The best apparent quadratic proposal
failed validation and produced negative test \(R^2\). AION rejected it.

This negative result is retained as evidence that external grounding does not
automatically authorize an explanation.

## Capability meaning

Within the tested grammar, AION can now form and test the proposition:

> “The remaining prediction error is structured. A nonlinear response, a
> delayed cause or an unobserved continuous state may explain it. I should
> construct competing operators, design an observation that separates them,
> and accept one only if it predicts unseen outcomes.”

This connects representation invention, experimental choice, program
construction, real outcome grounding, criticism and persistent learning in one
governed loop.

## Authority and claim boundary

The following remain engineered:

- scalar input/output traces;
- the primitive operator vocabulary;
- finite parameter grids;
- the synthetic family generators;
- development-authored software experiments;
- fixed chronological splits and acceptance ceilings.

The NOAA and Git/disk outcomes are independently produced observations, but
this experiment is not an externally administered evaluation. It does not
establish unrestricted operator invention, general scientific discovery or
AGI. The result establishes governed model-family construction and predictive
transfer within a bounded recursive grammar.

## Next frontier

multivariate real systems**:

   selecting one family;
2. infer variable interactions and multiple latent states;
3. learn continuous-time and irregularly sampled dynamics;
4. choose real measurements by expected information value and cost;
5. validate on source-disjoint software telemetry, public sensor networks and
   independently authored operational traces;
6. require calibrated uncertainty, causal intervention tests where available,
