# AION Open Authority-Disagreement Diagnosis and Tier-5 Escalation

## Result

AION has promoted a diagnostic-program invention procedure and used it inside
live autonomous consequence contracts.

Promoted procedure:

`procedure_open_authority_disagreement_diagnosis_v1`

The procedure receives conflicting claims without a supplied failure label and
searches compositions of safe information probes.  Its retained program uses:

1. canonical evidence integrity;
2. authority-observation temporal alignment;
3. alternate parser cross-checking; and
4. counterfactual robustness under contamination.

It distinguishes four operationally different causes:

| Cause | Diagnostic response |
|---|---|
| Evidence corruption | Reacquire and quarantine |
| Environmental change | Reobserve and replan |
| Adapter failure | Create a private adapter repair |
| Method failure | Start a private method challenger |

The first live attempt was rejected.  Madrid weather payloads changed while the
payload's rounded observation timestamp remained equal.  The revised diagnostic
preserved both authority-observation time and payload time, correctly resolving
the change as environmental rather than corrupted evidence.

## Claim boundary

This is bounded open diagnostic-program invention.  Four safe probe primitives,
the development scenarios and routing destinations remain engineered.  It is
not unrestricted scientific diagnosis.  Its significance is that conflicting
credible evidence no longer forces AION to guess, average the claims or blame
its own runtime indiscriminately.
