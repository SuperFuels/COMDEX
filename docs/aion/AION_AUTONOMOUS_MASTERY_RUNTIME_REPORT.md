# AION Autonomous Mastery Runtime

## Promotion

Two internally evaluated procedures are promoted:

- `procedure_open_diagnostic_experiment_invention_v1`
- `procedure_autonomous_mastery_runtime_v1`

This stage does not create another cognitive loop. It removes two supplied
dependencies from the canonical AION runtime: clean post-outcome failure labels
and a fixed five-specialist mission vocabulary.

## Runtime chain

```text
immutable owner mission
  -> open learning-target induction
  -> target-specific specialist-contract invention
  -> dependency graph
  -> weakest ready capability
  -> self-generated curriculum task
  -> self-generated pre-action criticism
  -> committed bounded action
  -> independent outcome
  -> ambiguous failure: active diagnostic experiment
  -> scoped reflection / private repair
  -> transfer + retention test
  -> persistent mastery update
```

The runtime may invent instrumental goals. It cannot authorize its own terminal
mission. Compilation is proposal-only unless the owner/runtime boundary passes
`authorize=True`; after authorization, the terminal objective hash is immutable.

## Open diagnostic experiment invention

When several failure explanations remain plausible, AION preserves them rather
than accepting a supplied label. It inspects read-only observation contracts,
predicts how each live hypothesis partitions possible outcomes, and selects the
observation with maximum information per unit cost. Predictions and the selected
experiment are hash-committed before the evaluator reveals the result.

Six sealed cases covered assumption, decision-model, execution, evidence,
environment and authority failures. Channel names were changed in every case.

## Self-generated pre-action criticism

For consequential actions without planner-supplied opposition, the
metacognitive controller now negates material assumptions, constructs an
opposing failure scenario, and proposes a low-risk information action. These
outputs are explicitly unverified and proposal-only. Five domains generated
five counterfactual and information-action sets with zero LLM calls.

## Open capability and specialist invention

The compiler extracted four owner learning targets from one natural mission:

1. Rust systems engineering;
2. accessible user-interface design;
3. evidence-grounded financial-market analysis; and
4. bioacoustic event classification.

The fourth target was intentionally outside the retained five-domain cognitive
vocabulary. For every target, AION created target-specific specialist contracts
for evidence modelling, deliberate practice, source-disjoint transfer and
retention. It then created a cross-target integration contract, producing 17
specialist contracts in total.

Every contract declares inputs, outputs, prerequisites, outcome authority and
proposal-only status. Graph construction fails closed when the mission lacks a
clear learning target or an independent outcome authority.

## Persistent mastery control

The controller selects the dependency-ready capability with the highest
strategic weakness score. Verified method outcomes change the order of later
candidate evaluations. Development success alone is insufficient: each
capability requires an unfamiliar transfer outcome, and retention is represented
as its own downstream specialist contract.

## Live integration

`CanonicalAionCognitiveRuntime.compile_and_authorize_mastery_mission` now exposes
the compiler to the persistent runtime. Proposal and authorization are separate
operations. Invented contracts are retained beside the mission envelope and
ordinary confidence-based curriculum generation can schedule their tasks.

The runtime also recognises ambiguous post-action reflection. If the critic
provides competing causal models and safe observation contracts, the open
diagnostic engine constructs the next information action. If no safe informative
observation exists, it abstains.

## Claim boundary

This is a persistent semi-autonomous mastery controller, not proof that AION has
already mastered Rust, interface design, finance or bioacoustics. The sealed
method-property authority, generic four-phase mastery scaffold and diagnostic
observation contracts remain engineered. It demonstrates that AION can invent
new target-specific specialist contracts, order them, learn a reusable method
policy from consequences, diagnose ambiguous failures actively, retain progress
and protect terminal owner intent.

The next capability gate is real apprenticeship: bind an authorized target to
authoritative resources, actual toolchains and unfamiliar projects; let AION
generate exercises and diagnostic interventions; and require repeated external
execution, user, market-data or sensor consequences before any subject is
reported as mastered.
