\section{HexCore Phases 46--48: Mathematical Operators, Tool Invention, and Persistent Projects}
\label{sec:hexcore-phases-46-48}

\subsection{Scope and authority boundary}

Phases 46--48 extend AION along three connected axes: mathematical abstraction, governed executable invention, and persistent multi-stage project control.  Every learned object remains subordinate to execution-based verification and Cognitive Authority Unification (CAU).  The resulting capabilities are bounded and inspectable; they do not establish unrestricted mathematical discovery, arbitrary software synthesis, autonomous real-world project execution, or artificial general intelligence.

\subsection{Phase 46: algebraic and continuous operator learning}

The discrete path exhaustively evaluates each of four Phase~45 predicates over 27 three-valued assignments.  It records symmetry, reflexivity, irreflexivity, transitivity, monotonicity, equivalence-relation status, and recursive path soundness.

The continuous path searches a fixed symbolic feature grammar:
\[
\phi(x,y)=
\left[
x+y,\;
xy,\;
|x-y|,\;
(x+y)^2,\;
x^3+y^3,\;
(x-y)^2
\right].
\]
All one- and two-feature supports are fitted by least squares.  A minimum-description-length/BIC-style penalty selects a compact model,
\[
\mathcal{J}(M)
=
n\log\!\left(\operatorname{MSE}(M)+10^{-10}\right)
+2.5\,k\log n,
\]
where \(k\) is the number of fitted coefficients.  Models are evaluated on unseen continuous points, under recursive composition, and against independently coded external reference functions.

\subsection{Phase 47: governed Photon tool invention}

The inventor searches a bounded candidate library when an operation cannot be performed by one existing primitive.  Candidate capsules conform to \texttt{aion.photon.numeric\_tool.v1}.  A static kernel guard and a second abstract-syntax-tree allowlist restrict execution to declared scalar inputs, constants, bounded arithmetic, and \texttt{abs}, \texttt{min}, and \texttt{max}.  Imports, file access, networking, unrestricted calls, and dynamic evaluation in candidate programs are prohibited.

The governed path is:
\[
\text{gap}
\rightarrow
\text{capsule proposals}
\rightarrow
\text{safety checks}
\rightarrow
\text{sandbox execution}
\rightarrow
\text{sealed transfer}
\rightarrow
\text{CAU promotion}.
\]

Four tools were invented: squared separation, coupled flux, threshold margin, and bounded balance.  Across the sealed and independent external cases, exact accuracy and weakest-family accuracy were 100\%.  All five malicious probes were rejected, provenance was complete, restart retention was exact, and the retained one-call tools reduced repeated primitive-operation cost by 71.43\%.  This cost figure is an operation-count comparison, not a hardware throughput claim.

The promoted procedure is
\texttt{procedure\_governed\_tool\_invention\_852fbd569125}.

\subsection{Phase 48: persistent long-horizon project intelligence}

Each project is stored as a durable state machine containing a milestone plan, completed work, unresolved questions, artifacts, provenance, plan revisions, and a chronological execution trace.  Projects traverse six milestones: brief ingestion, rule grounding, tool invention, external-change monitoring, case execution, and final verification.

The runtime is forcibly reconstructed after three milestone boundaries.  When an external rule changes, AION supersedes the obsolete rule, records the reason and source revision, and revises only the affected future milestones.

\subsection{Interpretation and remaining boundary}

These phases connect an important chain:
\[
\text{infer a reusable operation}
\rightarrow
\text{compile it into a governed tool}
\rightarrow
\text{use retained tools in persistent revised projects}.
\]
The task grammars, scalar interfaces, project milestones, change events, simulators, and correctness oracles remain engineered.  The next programme must test the same mechanisms against source-disjoint natural documents, unfamiliar schemas, richer executable environments, longer time horizons, multimodal evidence, and independent external evaluators.
