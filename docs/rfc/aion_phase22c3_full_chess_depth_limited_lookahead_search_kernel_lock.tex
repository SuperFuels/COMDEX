\section{Purpose}

Phase 22C.2 selected moves by scoring the immediate position after each legal move.

Phase 22C.3 extends this into lookahead by simulating future legal continuations and opponent replies before selecting a move.

\section{Kernel Location}

\begin{verbatim}
backend/modules/aion_games/full_chess_depth_limited_lookahead_search_kernel.py
\end{verbatim}

\section{Search Contract}

The kernel MUST:

\begin{itemize}
  \item generate legal candidate moves;
  \item simulate future legal continuations up to a depth limit;
  \item include opponent replies;
  \item evaluate leaf positions with the Phase 22C.1 evaluator;
  \item prioritise terminal mate moves;
  \item avoid emitting moves from terminal positions;
  \item emit node and leaf evaluation counts;
  \item emit a deterministic search trace hash;
  \item avoid Stockfish, cloud engines, and LLM move judgement.
\end{itemize}
