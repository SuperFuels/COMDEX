\section{Phase 21A --- AION-LRM Pilot / Boardroom Integration Discovery Lock}
\label{sec:phase21a-lrm-pilot-boardroom-integration-discovery-lock}

\subsection{Status}

\begin{quote}
\textbf{Status: LOCKED --- discovery-only integration map for connecting AION-LRM to the existing Pilot and Boardroom surfaces.}
\end{quote}

\subsection{Purpose}

Phase 21A records the correct existing integration points for connecting the Phase 20 AION-LRM loop into the already-existing AION Pilot and Boardroom runtime.

This phase is discovery-only.

It MUST NOT implement new runtime behaviour, mount new UI, add live execution authority, write business-container records, or create a parallel Pilot system.

\subsection{Reason For This Lock}

The repository already contains a substantial Pilot / Mission Mode stack.

Therefore Phase 21 MUST integrate with the existing stack instead of guessing or creating a duplicate surface.

The correct design rule is:

\begin{quote}
AION-LRM SHOULD become an intelligence overlay for the existing Pilot and Boardroom surfaces, not a replacement Pilot.
\end{quote}

\subsection{Integration Rule}

Phase 21 SHOULD connect the Phase 20I end-to-end LRM loop to the existing Pilot and Boardroom stack by exposing LRM state as preview/read-only intelligence context.

The first safe integration target SHOULD be a backend payload adapter, not direct UI changes.

The adapter SHOULD read or build:

\begin{itemize}
  \item the Phase 20I LRM end-to-end decision loop;
  \item Pilot mission identity;
  \item mission run identity;
  \item Boardroom display state;
  \item artifact/proof/receipt hashes;
  \item evidence gap and evidence satisfaction state;
  \item human review state.
\end{itemize}

It SHOULD emit a Boardroom/Pilot-safe payload that can later be mounted in the existing Pilot cockpit.

\subsection{Explicit Non-Goals}

Phase 21A MUST NOT:

\begin{itemize}
  \item create a new Pilot system;
  \item create a new Boardroom surface;
  \item bypass \texttt{renderBoardroomDashboardView};
  \item bypass \texttt{renderAionPilotCockpitPanel};
  \item write live business-container data;
  \item send external messages;
  \item create bookings;
  \item create payments;
  \item create escrow;
  \item write live chain data;
  \item execute workflow steps;
  \item expose private chain-of-thought;
  \item expose hidden reasoning;
  \item expose credentials.
\end{itemize}
