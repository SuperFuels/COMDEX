\section{Adapter Contract}

The adapter MUST:

\begin{itemize}
  \item accept live board state as moves or FEN;
  \item determine whether it is AION's turn;
  \item call the Phase 22D.2 SQI-guided selector when it is AION's turn;
  \item emit no move when it is not AION's turn;
  \item emit no move from terminal positions;
  \item prove the selected move is legal;
  \item preserve SQI trace and selection trace hashes;
  \item run in dry-run mode by default;
  \item avoid sending live Lichess moves in this phase.
\end{itemize}
