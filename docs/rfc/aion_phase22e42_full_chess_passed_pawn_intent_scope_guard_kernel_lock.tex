\section{Rule}

If active intent is \texttt{convert\_passed\_pawn}, the selected move SHOULD be:

\begin{itemize}
  \item a legal promotion; or
  \item a pawn move directly progressing toward promotion.
\end{itemize}

Otherwise the intent MUST be scoped back to initiative pressure.
