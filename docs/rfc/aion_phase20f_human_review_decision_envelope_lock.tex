\end{quote}

\subsection{Purpose}

Phase 20F turns the reasoning recommendation card into a governed human review decision envelope.

The envelope allows the operator-facing layer to record one of three preview-only decisions:

\begin{verbatim}
approve_preview
reject
request_more_evidence
\end{verbatim}

The decision envelope does not grant live execution permission.

\end{verbatim}

\subsection{Decision Contract}

The envelope records:

\begin{itemize}
  \item business id;
  \item recommendation card hash;
  \item recommendation summary hash;
  \item human review decision;
  \item reviewer id;
  \item reviewer note;
  \item requested evidence;
  \item blocked live actions;
  \item deterministic envelope hash;
  \item deterministic summary hash.
\end{itemize}

\subsection{Safety Boundary}

Phase 20F is preview-only.

Even \texttt{approve\_preview} only approves continuation to the next preview or review stage.

It MUST NOT:

\begin{itemize}
  \item create a booking;
  \item create a payment;
  \item create escrow;
  \item send an external message;
  \item write live chain data;
  \item execute a workflow;
  \item grant live permission.
\end{itemize}

\subsection{Private Reasoning Boundary}

The decision envelope MUST NOT expose private chain-of-thought, hidden reasoning, credentials, access tokens, API keys, passwords, or secrets.
