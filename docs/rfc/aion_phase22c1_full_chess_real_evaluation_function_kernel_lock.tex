\section{Purpose}

Earlier phases proved that AION could generate legal moves, send live Lichess moves, complete a live game, and perform post-game review.

Phase 22C.1 moves the chess stack toward real strategic selection by evaluating board positions numerically.

\section{Evaluation Terms}

The evaluation function scores:

\begin{itemize}
  \item material balance;
  \item king safety;
  \item piece activity;
  \item centre control;
  \item development;
  \item pawn structure;
  \item repetition-risk penalty;
  \item check pressure;
  \item terminal mate or draw awareness.
\end{itemize}

\section{Learning Integration}

The evaluator may load policy weights from:

\begin{verbatim}
data/aion_games/full_chess_post_game_blunder_review_memory.json
\end{verbatim}

The loaded weights can influence:

\begin{itemize}
  \item king-safety weighting;
  \item piece-activity weighting;
  \item repetition penalty weighting;
  \item queen-activity penalty weighting.
\end{itemize}
