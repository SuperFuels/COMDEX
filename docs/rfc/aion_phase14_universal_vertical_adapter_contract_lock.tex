\subsection{Purpose}

Phase 14B locks the first universal vertical adapter contract for the AION Gateway.

The purpose is to prove that AION is not a trade-only or Home Fixed-only gateway. Home Fixed remains the active live/test vertical, but the machine gateway MUST remain universal across future verticals.

The adapter maps vertical-specific business language into a stable universal shape that can later feed AgentMap, A2A discovery, public gateway previews, quote previews, proof routes, trust summaries, and human-review handoff.

\subsection{Implemented Module}

The implementation lives in:

\begin{verbatim}
backend/modules/aion_gateway/universal_vertical_adapter.py
\end{verbatim}

The module exposes:

\subsection{Universal Contract}

The adapter contract defines a universal field vocabulary:

\begin{itemize}

  \item customer
  \item intent
  \item service
  \item quote
  \item availability
  \item booking preview
  \item evidence
  \item proof
  \item trust

These fields are intentionally cross-industry. They are not Home Fixed-specific and not trade-only.

\subsection{Home Fixed Mapping}

The Home Fixed adapter maps home repair language into universal fields:

\begin{itemize}
  \item jobs map to service
  \item quotes map to quote
  \item availability maps to availability
  \item evidence maps to evidence
  \item proof receipts map to proof
  \item trust summaries map to trust
  \item human review handoff maps to human review
\end{itemize}

This proves the concrete Home Fixed testbed can use the universal adapter without forcing the gateway to become a trade-only system.

\subsection{Deterministic Hashes}

The adapter emits deterministic hashes:

\begin{itemize}
  \item \texttt{adapter\_hash}
  \item \texttt{summary\_hash}
\end{itemize}

The hash contract MUST be canonical, deterministic, and independent of runtime randomness, wall-clock timestamps, live provider state, payment state, booking state, external message state, mutable UI state, or chain-write state.

\subsection{Safety Boundary}

The universal vertical adapter is preview-only.

It MUST NOT:

\begin{itemize}
  \item create a booking,
  \item create a live job,
  \item execute the Goal Engine,
  \item bypass human review,
  \item move money,
  \item move PHO,
  \item require a wallet,
  \item create a payment,
  \item create escrow,
  \item release funds,
  \item send external messages,
  \item dispatch a job,
  \item write live chain data,
  \item mount a public route.
\end{itemize}

The locked safety state includes:

\begin{verbatim}

human_review_required = true

would_create_live_job = false
would_execute_goal_engine = false
would_move_money = false
