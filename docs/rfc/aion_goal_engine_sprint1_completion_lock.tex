\subsection{Dry-Run Bridge Lock}

The Workflow Capsule dry-run bridge now attaches Goal Engine data to the final \texttt{WorkflowDryRunResult}, not to per-step permission dictionaries.

This prevents permission evaluation from becoming polluted with Goal Engine manifest state.

The bridge contract is:

\begin{itemize}
  \item attach the canonical preview bundle once,
  \item expose legacy mirrors from the bundle,
  \item preserve one step-trace attachment path,
  \item prevent duplicate trace rows,
  \item keep all Goal Engine output dry-run only,
  \item grant no permission,
  \item perform no external writes.
\end{itemize}

\subsection{Safety Lock}

Sprint 1 remains non-executing.

The locked safety contract is:

\begin{itemize}
  \item Goal nodes do not grant permission.
  \item Experiment nodes do not grant permission.
  \item Loop nodes do not grant permission.
  \item Reflection and learning nodes do not grant permission.
  \item External writes require explicit approval.
  \item Unbounded loops are not allowed.
  \item Resume requires environment revalidation.
  \item A2A is deferred until the Goal Engine is stable.
\end{itemize}

\subsection{Workflow Canvas Lock}

The Workflow Canvas is the single editing and composition surface.

The separate Master Glyph Canvas mode is deprecated as a separate canvas mode. Reusable glyph workflows are managed through the Glyph Library modal and opened as tabs inside the main Workflow Canvas.

Goal Engine capability is built on the Workflow Canvas.

Boardroom is the trust and explanation layer.
