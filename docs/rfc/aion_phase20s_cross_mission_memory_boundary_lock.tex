\section{AION Phase 20S --- Cross-Mission Memory Boundary}
\label{sec:aion-phase20s-cross-mission-memory-boundary}

\subsection{Status}

Phase 20S locks the cross-mission memory boundary.

\begin{quote}
\textbf{Status: LOCKED --- mission data cannot leak into later missions unless explicitly approved.}
\end{quote}

\subsection{Purpose}

Mission-local data MUST NOT silently become global memory or future mission context.

Phase 20S prevents accidental and malicious cross-mission leakage.

\begin{quote}
\textbf{Mission B MUST NOT inherit Mission A data unless explicitly allowed.}
\end{quote}

\subsection{Mission Memory Scopes}

Mission memory records MUST declare one of:

\begin{itemize}
  \item \texttt{session}
  \item \texttt{mission}
  \item \texttt{business\_proposal}
  \item \texttt{forbidden}
\end{itemize}

\subsection{Default Boundary}

Cross-mission access is blocked by default.

Mission-scoped data MAY be read by the same mission, but MUST NOT be read by a later mission without explicit approval.

\subsection{Data Retention Policy}

The memory boundary MUST respect \texttt{data\_retention\_policy}.

For \texttt{mission\_scoped} data, access outside the source mission is rejected unless an approved transfer hash exists.

\subsection{Business Memory Proposal}

AION Pilot MUST NOT silently promote mission data to business memory.

Reusable learning must be converted into a memory promotion proposal containing:

\begin{itemize}
  \item source mission ID;
  \item target business ID;
  \item key;
  \item proposed value hash;
  \item reason;
  \item proposed by;
  \item approval state;
  \item proposal hash.
\end{itemize}

\subsection{Human Approval}

A business memory promotion becomes valid only after human approval.

The approval MUST emit:

\begin{verbatim}
approval_hash: sha256:<digest>
\end{verbatim}

\subsection{Accidental Leakage Guard}

The memory boundary MUST test realistic accidental leakage, not only malicious leakage.

If a later mission context contains source mission identifiers or mission-scoped data without an approved transfer, the context MUST be blocked.
