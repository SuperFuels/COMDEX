\subsection{Purpose}

Phase 20H handles the moment when missing evidence is supplied after a Phase 20G evidence gap.

The Evidence Intake / Evidence Satisfaction Envelope records:

\begin{itemize}
  \item what evidence was received;
  \item which evidence hashes were attached;
  \item which evidence gap it satisfies;
  \item which recommendation card it unblocks;
  \item which proof hashes and context hashes it links to;
  \item whether the request may return to human review.
\end{itemize}

The envelope does not approve live execution.

It only determines whether the evidence gap is satisfied enough to return the case to human review.

\subsection{Satisfaction Contract}

The envelope records:

\begin{itemize}
  \item source evidence gap hash;
  \item source evidence gap summary hash;
  \item received evidence;
  \item evidence hashes;
  \item required evidence;
  \item remaining missing evidence;
  \item evidence gap satisfied flag;
  \item unblocked recommendation card hash;
  \item proof hashes;
  \item context hashes;
  \item next review state;
  \item deterministic satisfaction hash;
  \item deterministic summary hash.
\end{itemize}

\subsection{Review State}

If all required evidence has been received, the next review state is:

\begin{verbatim}
return_to_human_review
\end{verbatim}

If evidence is still missing, the next review state remains:

\begin{verbatim}
request_more_evidence
\end{verbatim}
