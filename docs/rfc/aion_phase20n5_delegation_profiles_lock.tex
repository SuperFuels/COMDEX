\section{AION Phase 20N.5 --- Delegation Profiles and Autonomy Modes}
\label{sec:aion-phase20n5-delegation-profiles-autonomy-modes}

\subsection{Status}

Phase 20N.5 locks Delegation Profiles and Autonomy Modes.

\begin{quote}
\textbf{Status: LOCKED --- profile presets configure defaults only; the safety spine remains authoritative.}
\end{quote}

\subsection{Purpose}

Delegation profiles allow the user to start missions quickly using reusable autonomy presets.

Profiles MUST NOT bypass the classifier, kernel guard, approval lattice, payload approval, expiry rules, checkpoint rules, or blocked state.

\subsection{Profiles}

AION defines four profile presets:

\begin{itemize}
  \item \texttt{safe\_draft\_mode};
  \item \texttt{business\_setup\_mode};
  \item \texttt{trusted\_operator\_mode};
  \item \texttt{emergency\_lockdown\_mode}.
\end{itemize}

\subsection{Safe Draft Mode}

Safe Draft Mode permits draft and preview work only.

No external side effects are allowed.

\subsection{Business Setup Mode}

Business Setup Mode allows AION Pilot to build and prepare work, including read-only external research, but requires approval for spend, deployment, publishing, messaging, ownership actions, and live external effects.

\subsection{Trusted Operator Mode}

Trusted Operator Mode allows more read-only and staged work under caps.

Live high-risk actions still require exact payload approval.

\subsection{Emergency Lockdown Mode}

Emergency Lockdown Mode blocks autonomous execution and allows only proof, replay, and recovery-style inspection paths.

\subsection{Always Approval Required}

The following actions remain approval-required under all profiles:

\begin{itemize}
  \item payments;
  \item legal actions;
  \item identity actions;
  \item production deployments;
  \item domain purchases;
  \item new ad spend;
  \item live customer messages;
  \item public publishing.
\end{itemize}

\subsection{Profile Safety Rule}

Profiles set defaults only.

The effective decision MUST still be resolved through the approval lattice:

\begin{equation}
\mathcal{D}_{\mathrm{effective}}
=
\sup
(
\mathcal{D}_{\mathrm{system}},
\mathcal{D}_{\mathrm{profile}}
)
\end{equation}
