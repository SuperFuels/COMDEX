\section{Purpose}

Phase 22E.28 introduces a one-ply blunder guard for AION full chess.

The guard checks whether a candidate move allows an immediate catastrophic opponent reply.

\section{Contract}

The guard MUST inspect all legal opponent replies after the candidate move.

It MUST detect:

\begin{itemize}[leftmargin=*]
  \item immediate checkmate replies;
  \item checking replies;
  \item queen loss;
  \item rook or major material loss;
  \item illegal candidate moves;
  \item whether the candidate remains safe to send.
\end{itemize}

The guard exposes the final send decision as:

\begin{verbatim}
safe_to_send
\end{verbatim}

\section{Boundary}

This phase does not use Stockfish, does not use LLM move judgement, and does not use Lichess analysis.
