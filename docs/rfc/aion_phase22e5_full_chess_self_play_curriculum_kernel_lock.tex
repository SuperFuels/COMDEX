\section{Purpose}

Phase 22E.5 introduces a deterministic self-play curriculum layer with increasing difficulty.

This phase consumes Phase 22E.4 post-game strategic policy updates and converts them into repeatable curriculum pressure.

\section{Curriculum Contract}

The kernel tracks:

\begin{itemize}[leftmargin=*]
  \item episode count;
  \item curriculum level;
  \item selected policy profile;
  \item plan-follow rate;
  \item positional-delta trend;
  \item mate-loss reduction;
  \item promotion-danger reduction;
  \item invasion-risk reduction;
  \item trace hash per episode.
\end{itemize}

\section{Policy Integration}

The curriculum consumes post-game strategic policy updates such as:

\begin{itemize}[leftmargin=*]
  \item increase king-safety goal bias after mate loss;
  \item increase invasion reduction after back-rank penetration;
  \item increase promotion defence after an unstopped pawn;
  \item increase positional-delta weighting after decline.
\end{itemize}

\section{Boundary}

This phase does not use Stockfish, cloud engines, Lichess analysis, LLM move judgement, or human move scoring.

It is deterministic local curriculum pressure over AION chess telemetry.
