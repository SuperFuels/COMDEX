\subsection{Bounded Orchestration Rule}

Orchestration MUST be bounded before execution.

A bounded orchestrator MUST define:

\begin{itemize}
  \item at least one valid agent assignment;
  \item a supported \texttt{coordination_mode};
  \item a supported \texttt{conflict_policy};
  \item \texttt{max_parallel_agents > 0};
  \item bounded child timeout semantics.
\end{itemize}

Unbounded orchestration MUST emit:

\begin{verbatim}
unbounded_orchestration_blocked
\end{verbatim}
