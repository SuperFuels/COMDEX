\section{Purpose}

Phase 22E.32 introduces plan continuity memory for AION full chess.

The kernel remembers the previous strategic plan and scores whether the next candidate move continues, changes, or breaks that plan.

\section{Contract}

The kernel MUST infer or accept a current plan.

It MUST remember the previous strategic plan and emit:

\begin{verbatim}
plan_changed
continuity_score
move_supports_plan
move_breaks_plan
recommended_plan
\end{verbatim}

The kernel SHOULD detect plans such as:

\begin{itemize}[leftmargin=*]
  \item \texttt{convert\_passed\_pawn};
  \item \texttt{build\_mate\_net};
  \item \texttt{build\_rook\_box};
  \item \texttt{simplify\_and\_convert};
  \item \texttt{escape\_or\_neutralise\_check};
  \item \texttt{improve\_position}.
\end{itemize}

\section{Boundary}

This phase does not use Stockfish, does not use LLM move judgement, and does not use Lichess analysis.
