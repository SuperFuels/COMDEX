\section{Purpose}

Phase 22E.9 introduces deterministic concept-guided search and plan bias.

This phase consumes Phase 22E.8 strategic concept memory and applies concept policy weights as a bias layer over strategic search and long-term plan generation.

\section{Bias Contract}

For each applied concept, the kernel emits:

\begin{itemize}[leftmargin=*]
  \item concept identifier;
  \item concept name;
  \item primary goal;
  \item policy weight;
  \item success rate;
  \item average risk reduction;
  \item reinforcement score;
  \item matched plan stage flag;
  \item matched search goal flag;
  \item bias score;
  \item bias trace hash.
\end{itemize}

\section{Technical Position}

This phase does not replace legal search output and does not send live moves.

It creates a deterministic bridge between strategic concept memory and search/planning. Deep move replacement and live-play integration are reserved for later phases.

\section{Boundary}

This phase does not use Stockfish, cloud engines, Lichess analysis, LLM move judgement, human move scoring, or live Lichess move sending.

It is deterministic local concept-guided search and plan bias over AION chess telemetry.
