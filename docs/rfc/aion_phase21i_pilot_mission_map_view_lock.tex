\section{Phase 21I --- Pilot Canvas / Mission Map View}
\label{sec:aion-phase21i-pilot-mission-map-view}

\subsection{Status}

\textbf{Status: LOCKED.}

Phase 21I defines the Pilot mission map read model.

\subsection{Purpose}

The Pilot mission map gives the user a visible step-by-step view of what AION Pilot is doing.

It shows mission steps, lanes, artifact links, receipt links, replay/proof links and blocked actions.

\subsection{Read Model Rule}

The mission map is a read model only.

It MUST NOT execute tools directly.

It MUST NOT mutate provider state, live memory, reputation, templates, payment state, deployment state, booking state, escrow state or external messages.

\subsection{Visible Lanes}

The mission map supports:

\begin{itemize}
  \item autonomous preview;
  \item approval required;
  \item human task required;
  \item blocked.
\end{itemize}
