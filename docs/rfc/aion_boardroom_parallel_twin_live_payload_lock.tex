\subsection{Purpose}

Phase 9A added a safe visual placeholder.

Phase 9B connects that visibility concept to a deterministic internal payload built from the Home Fixed vertical dry-run.

This remains internal and preview-only. It does not expose a public A2A route, execute the Goal Engine, create bookings, send messages, create payments, create escrow, require a wallet, or move money.

business_id = home_fixed

\end{verbatim}

\subsection{Hashing Rule}

The \texttt{payload\_hash} is deterministic and derived from stable JSON:

\begin{verbatim}
json.dumps(payload, sort_keys=True, separators=(",", ":"))
hashlib.sha256(...)
\end{verbatim}

Changing the job identity or any payload section MUST change the \texttt{payload\_hash}.
