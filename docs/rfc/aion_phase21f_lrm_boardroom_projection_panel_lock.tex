\subsection{Status}

\begin{quote}
\textbf{Status: LOCKED --- read-only AION-LRM Boardroom projection panel mounted in the existing Boardroom dashboard.}
\end{quote}

\subsection{Purpose}

Phase 21F renders the same AION-LRM context used by the Pilot stream as a Boardroom projection-only panel.

It uses the existing frontend state populated by the Phase 21D fetch bridge.

It does not fetch data itself.

It does not replace the Boardroom.

It does not create a duplicate Pilot.

\subsection{Safety Boundary}

Phase 21F is read-only and projection-only.

It MUST NOT:

\begin{itemize}
  \item fetch data itself;
  \item create a duplicate Pilot;
  \item replace the Boardroom;
  \item create a booking;
  \item create a payment;
  \item create escrow;
  \item send an external message;
  \item write live chain data;
  \item execute workflow steps;
  \item write business-container files;
  \item expose private chain-of-thought;
  \item expose hidden reasoning;
  \item expose credentials.
\end{itemize}
