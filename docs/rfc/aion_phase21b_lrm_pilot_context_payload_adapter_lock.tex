\section{Phase 21B --- LRM Pilot Context Payload Adapter v0}
\label{sec:phase21b-lrm-pilot-context-payload-adapter-v0}

\subsection{Status}

\begin{quote}
\textbf{Status: LOCKED --- backend adapter created for exposing AION-LRM state to existing Pilot and Boardroom surfaces.}
\end{quote}

\subsection{Purpose}

Phase 21B creates the LRM Pilot Context Payload Adapter.

The adapter connects the Phase 20I AION-LRM end-to-end decision loop to the existing AION Pilot and Boardroom architecture.

It does not create a new Pilot.

It emits a preview-only payload that can be consumed by the existing Pilot cockpit and Boardroom surfaces in a later frontend phase.

\subsection{Implemented Module}

\begin{verbatim}
backend/services/aion_mission_mode/lrm_pilot_context_payload_adapter.py
\end{verbatim}

The module exports:

\begin{verbatim}
LRM_PILOT_CONTEXT_PAYLOAD_ADAPTER_VERSION
build_lrm_pilot_context_payload
build_default_home_fixed_lrm_pilot_context_payload
\end{verbatim}

\subsection{Input}

The adapter accepts a Phase 20I AION-LRM loop:

\begin{verbatim}
backend/modules/aion_lrm/lrm_end_to_end_decision_loop.py
\end{verbatim}

If no loop is supplied, it builds the default Home Fixed preview loop.

\subsection{Output Contract}

The adapter emits:

\begin{itemize}
  \item payload version;
  \item business id;
  \item mission id;
  \item mission run id;
  \item business container root;
  \item source LRM loop hash;
  \item source LRM loop summary hash;
  \item LRM state summary;
  \item pilot cockpit projection;
  \item Boardroom projection;
  \item safety flags;
  \item deterministic payload hash;
  \item deterministic summary hash.
\end{itemize}

\subsection{Pilot Cockpit Projection}

The \texttt{pilot\_cockpit\_projection} contains the read-only context needed by the existing Pilot cockpit.

It includes:

\begin{itemize}
  \item mission identity;
  \item mission run identity;
  \item preview-only mode;
  \item visible stream events;
  \item artifact references;
  \item receipt references;
  \item blocked actions.
\end{itemize}

The projection is shaped for the existing frontend concepts:

\begin{verbatim}
getAionPilotCockpitSnapshot
renderAionPilotCockpitPanel
renderAionPilotSimpleTaskStream
renderAionPilotFrontendStreamEvents
\end{verbatim}

\subsection{Boardroom Projection}

The \texttt{boardroom\_projection} contains a read-only Boardroom summary of the same LRM state.

It includes:

\begin{itemize}
  \item loop hash;
  \item recommendation card hash;
  \item human review decision hash;
  \item evidence gap hash;
  \item evidence satisfaction hash;
  \item next review state.
\end{itemize}

It is projection-only and must not act as storage.

\subsection{Business Container Path Hint}

The adapter emits a deterministic business container path hint:

\begin{verbatim}
business/home-fixed/missions/<mission_id>/runs/<mission_run_id>
\end{verbatim}

This path is only a preview/path hint in Phase 21B.

It does not write files.

\subsection{Safety Boundary}

Phase 21B is preview-only.

It MUST NOT:

\begin{itemize}
  \item create a booking;
  \item create a payment;
  \item create escrow;
  \item send an external message;
  \item write live chain data;
  \item execute workflow steps;
  \item grant live permission;
  \item bypass human review;
  \item write business-container files;
  \item expose private chain-of-thought;
  \item expose hidden reasoning;
  \item expose credentials.
\end{itemize}
