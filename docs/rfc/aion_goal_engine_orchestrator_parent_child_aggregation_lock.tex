\subsection{Safety Invariants}

The aggregation preview is visibility only.

It MUST NOT:
\begin{itemize}
  \item mutate parent goals;
  \item mark a parent goal complete automatically;
  \item execute child agents;
  \item write to external systems;
  \item grant permissions;
  \item bypass human review.
\end{itemize}

A fully completed child set still requires manual review before parent completion.
