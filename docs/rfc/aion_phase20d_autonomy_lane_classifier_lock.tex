\section{AION Phase 20D --- Autonomy Lane Classifier v0}
\label{sec:aion-phase20d-autonomy-lane-classifier-lock}

\subsection{Status}

Phase 20D locks the deterministic Autonomy Lane Classifier for AION Mission Mode / AION Pilot.

\begin{quote}
\textbf{Status: LOCKED --- deterministic classifier only. No LLM calls, no live tools, no external writes.}
\end{quote}

\subsection{Purpose}

The classifier sits between the deterministic Mission Planner and the Mission Runtime.

Planner and LLM-provided labels are advisory only. The classifier owns the final lane and execution decision.

\subsection{Lanes}

The supported lanes are:

\begin{itemize}
  \item \texttt{research}
  \item \texttt{creation}
  \item \texttt{internal\_ops}
  \item \texttt{external\_action}
  \item \texttt{financial\_action}
  \item \texttt{legal\_action}
  \item \texttt{deployment\_action}
  \item \texttt{memory\_mutation}
\end{itemize}

\subsection{Decisions}

Every step is assigned one of:

\begin{itemize}
  \item \texttt{safe\_autonomous}
  \item \texttt{checkpoint\_required}
  \item \texttt{blocked}
  \item \texttt{forbidden}
\end{itemize}

\subsection{Safety Rule}

External, financial, legal, deployment, and memory mutation actions MUST NOT be classified as \texttt{safe\_autonomous}.

Unknown actions MUST be blocked until explicitly classified.

Live/raw actions such as live WhatsApp sends, live email sends, payment capture, production deploys, raw terminal execution, and live reputation writes are forbidden.
