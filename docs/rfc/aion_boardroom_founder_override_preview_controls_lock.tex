\subsection{Purpose}

The purpose of this lock is to show the future founder control path without allowing live execution.

The controls provide a preview of the approval actions that will later route through a guarded approval path.

\subsection{Preview Actions}

The locked preview action vocabulary is:

\begin{itemize}
  \item \texttt{approve},
  \item \texttt{reject},
  \item \texttt{request\_evidence},
  \item \texttt{escalate},
  \item \texttt{pause}.
\end{itemize}

All controls are disabled and marked preview-only.

\subsection{Future Route}

Each preview action points to:

\begin{verbatim}
future_guarded_approval_path
\end{verbatim}

No action is allowed to execute until the guarded approval path is implemented and locked.

\subsection{Safety Boundary}

The founder override preview controls MUST NOT:

\begin{itemize}
  \item execute workflows,
  \item create bookings,
  \item bypass human review,
  \item move money,
  \item move PHO,
  \item require a wallet,
  \item create a payment,
  \item create escrow,
  \item send external messages,
  \item expose a public A2A route.
\end{itemize}
