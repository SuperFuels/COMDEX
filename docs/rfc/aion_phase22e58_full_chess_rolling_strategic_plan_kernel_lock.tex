\section{Purpose}

Phase 22E.58 adds a rolling strategic plan layer before move selection.

The purpose is to stop AION from selecting isolated good-looking moves without knowing what plan the move supports.

\section{Plan Fields}

The kernel produces:

\begin{itemize}
  \item game phase;
  \item primary plan;
  \item secondary plan;
  \item target weakness;
  \item setup sequence;
  \item fallback plan;
  \item opponent disruption risk;
  \item candidate plan moves;
  \item selected plan move.
\end{itemize}

\section{Strategic Boundary}

This phase does not post moves.

It does not call Stockfish, does not use Lichess analysis and does not use LLM move judgement.

It only generates an internal plan object that later kernels can consume.
