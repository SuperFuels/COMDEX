\subsection{Purpose}

This lock makes the child-run executor bridge visible to the dry-run and Boardroom surfaces without allowing autonomous execution.

The bridge packet remains a guarded handoff packet for the existing Workflow Capsule runtime. It is not itself an executor. It does not create workflow runs, write externally, mutate business state, or grant permissions.
