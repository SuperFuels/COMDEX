\subsection{Purpose}

Phase 20C introduces the AION Reasoning Replay Trace.

The purpose is to prove that AION can replay why it reached a recommendation using only governed artifacts:

\begin{itemize}
  \item governed reasoning packet,
  \item reasoning memory snapshot,
  \item evidence context,
  \item proof context,
  \item AgentMap context,
  \item Boardroom context,
  \item ETS context,
  \item deterministic hashes.
\end{itemize}

The replay trace MUST NOT expose private chain-of-thought.

It MUST NOT create side effects.

\subsection{Replay Contract}

The reasoning replay trace records:

\begin{itemize}
  \item trace version,
  \item trace type,
  \item runtime,
  \item preview-only state,
  \item governed reasoning packet context,
  \item reasoning memory snapshot context,
  \item evidence context,
  \item replay steps,
  \item operational explanation,
  \item safety state,
  \item deterministic replay trace hash,
  \item deterministic summary hash.
\end{itemize}

\subsection{Evidence and Proof Context}

The replay trace includes an \texttt{evidence\_context} block containing replay anchors such as:

\begin{verbatim}
source_reasoning_packet_hash
reasoning_memory_snapshot_hash
agentmap_hash
proof_hash
proof_receipt_id
ets_preview_only
\end{verbatim}

These hashes are replay and audit anchors only.

They MUST NOT grant permission or trigger execution.

\subsection{Private Reasoning Boundary}

The replay trace MUST NOT expose private chain-of-thought, hidden reasoning, scratchpads, credentials, access tokens, API keys, passwords, or secrets.

The locked rule is:

\begin{quote}
AION may replay a safe operational explanation, but it MUST NOT reveal private chain-of-thought.
\end{quote}
