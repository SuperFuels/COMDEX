\subsection{Purpose}

AION Pilot is an operator/agent surface, not a normal chat surface.

The primary cockpit therefore belongs in:

\begin{verbatim}
Live Agents -> Aion
\end{verbatim}

The top-level Aion chat tab may point users to the cockpit, but it MUST NOT be the primary operator surface.

\subsection{Visible Operator Identity}

The Live Agents Aion workspace MUST show that Pilot is:

\begin{itemize}
  \item a native AION runtime operator;
  \item not UI automation;
  \item plan-gated;
  \item preview/safety bounded;
  \item unable to perform live external side effects without exact approval.
\end{itemize}
