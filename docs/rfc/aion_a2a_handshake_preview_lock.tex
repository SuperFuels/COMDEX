\subsection{Purpose}

Phase 11I previews the future real A2A handshake flow without enabling live external-agent execution.

This phase adds three preview contracts:

\begin{itemize}
  \item real A2A handshake preview contract,
  \item quote negotiation preview contract,
  \item live status polling preview contract.
\end{itemize}

The lock exists to define the future agent-to-business handshake shape while preserving the current safety boundary.
