\label{sec:aion-parallel-business-catalog-lock}

\subsection{Status}

The AION Gateway now defines the first internal Parallel Business Twin catalog contract for Home Fixed.

\begin{quote}
\textbf{Status: LOCKED --- internal catalog preview only. No public route, no booking, no payment, no escrow, and no live Goal Engine execution.}
\end{quote}

\subsection{Purpose}

The Parallel Business Catalog is the machine-readable twin of a real business.

For humans, the normal website remains the primary surface. For agents, the catalog becomes the structured operational surface that describes what the business can do, where it operates, what evidence is required, and what safety boundaries apply.

The first live testbed business is:

\begin{quote}
\textbf{Home Fixed} --- home repair and building work across Almeria / Murcia.
\end{quote}

\subsection{Hashing Rule}

The catalog hash is computed from deterministic JSON:

\begin{verbatim}
json.dumps(payload, sort_keys=True, separators=(",", ":"))
hashlib.sha256(...)
\end{verbatim}

The hash is order-independent for service dictionary output.

Changing service data MUST change the \texttt{catalog\_hash}.

\subsection{Safety Boundary}

This lock is internal and preview-only.

The catalog MUST NOT:

\begin{itemize}
  \item create a booking,
  \item create a payment,
  \item create escrow,
  \item expose a public route,
  \item execute the Goal Engine,
  \item grant permission,
  \item move PHO, token, wallet value, or fiat.
\end{itemize}

\subsection{Strategic Role}

This module establishes the first concrete layer of the AION Parallel Business Infrastructure.

AION is positioned as the machine-readable operating twin provider for real-world businesses. The human website remains intact, while the AION-hosted twin provides structured machine access for future agent-to-agent commerce.
