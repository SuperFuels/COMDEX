\subsection{Purpose}

Phase 11C defines the next two machine-facing preview responses inside the guarded A2A namespace:

\begin{itemize}
  \item \texttt{business\_availability}
  \item \texttt{machine\_cart\_quote\_request\_preview}
\end{itemize}

These responses remain universal Gateway contracts.

Home Fixed is the default validation fixture only. Future verticals, including legal services, accounting services, healthcare, hospitality, property, restaurants, education, and consultancy, should use the same envelope with vertical-specific adapter rules.

\subsection{Business Availability Preview}

The \texttt{business\_availability} response advertises availability in preview-only form.

The response includes:

\begin{itemize}
  \item business identity,
  \item vertical identity,
  \item industry identity,
  \item timezone,
  \item availability windows,
  \item availability state,
  \item vertical mapping notes,
  \item safety flags,
  \item \texttt{availability\_hash}.
\end{itemize}

Availability windows MUST NOT create bookings.

Each window keeps:

\begin{verbatim}
booking_allowed = false
human_review_required = true
\end{verbatim}

\subsection{Machine Cart Quote Request Preview}

The \texttt{machine\_cart\_quote\_request\_preview} response accepts a machine-readable quote request shape and returns a quote preview only.

Required request fields are:

\begin{itemize}
  \item \texttt{business\_id}
  \item \texttt{vertical\_key}
  \item \texttt{service\_id}
  \item \texttt{requested\_outcome}
\end{itemize}

Missing required fields block the preview response.

\subsection{Quote Preview Boundary}

The quote preview MUST NOT create a final quote.

The locked quote preview state is:

\begin{verbatim}
status = quote_preview_only
final_quote_created = false
quote_negotiation_enabled = false
human_review_required = true
pricing_mode = requires_human_review
\end{verbatim}

The next step is a future guarded approval path:

\begin{verbatim}
future_guarded_approval_path
\end{verbatim}

\subsection{Determinism}

The availability response includes:

\begin{verbatim}
availability_hash
\end{verbatim}

The quote request preview response includes:

\begin{verbatim}
quote_request_hash
\end{verbatim}

The bundle response includes:

\begin{verbatim}
bundle_hash
\end{verbatim}

The hashes are deterministic for identical input and change when vertical identity changes.

\subsection{Safety Boundary}

The availability and quote preview responses MUST NOT:

\begin{itemize}
  \item expose a public route,
  \item create a booking,
  \item execute the Goal Engine,
  \item bypass human review,
  \item move money,
  \item move PHO,
  \item require a wallet,
  \item create a payment,
  \item create escrow,
  \item send external messages,
  \item negotiate a live quote.
\end{itemize}
