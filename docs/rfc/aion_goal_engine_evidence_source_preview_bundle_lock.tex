\subsection{Purpose}

This lock makes real evidence sources visible before any outcome, memory, or parent goal mutation can occur.

The evidence source layer is preview-only. It allows AION to show whether a goal has supporting evidence from external systems, without reading, writing, mutating, sending, granting permission, or marking success automatically.

Supported evidence pointer types include:

\begin{itemize}
  \item \texttt{gmail\_reply}
  \item \texttt{crm\_lead}
  \item \texttt{utm\_click}
  \item \texttt{booking}
  \item \texttt{payment}
  \item \texttt{file}
  \item \texttt{screenshot}
\end{itemize}

\subsection{Boardroom Visibility}

The Boardroom UI now mounts an \texttt{Evidence Sources} panel that reads from live preview bundle payloads.

The panel resolves evidence rows from:

\begin{itemize}
  \item \texttt{snapshot.evidence\_source\_runtime\_summary}
  \item \texttt{snapshot.goal\_engine\_evidence\_source\_runtime\_summary}
  \item \texttt{machineTrace.evidence\_source\_runtime\_summary}
  \item \texttt{machineTrace.goal\_engine\_evidence\_source\_runtime\_summary}
  \item \texttt{snapshot.evidence\_source\_previews}
  \item \texttt{snapshot.evidence\_pointer\_previews}
  \item \texttt{snapshot.goal\_engine\_evidence\_source\_previews}
  \item \texttt{snapshot.goal\_engine\_evidence\_pointer\_previews}
  \item \texttt{machineTrace.evidence\_source\_previews}
  \item \texttt{machineTrace.evidence\_pointer\_previews}
\end{itemize}

The panel is visibility-only. It MUST NOT read external systems live, write external systems, grant connector permissions, create approvals, or mark goal outcomes complete.

\subsection{Safety Invariants}

Evidence source previews MUST preserve these flags:

\begin{verbatim}
dry_run_only = true
would_read_external = false
would_write_external = false
would_grant_permission = false
\end{verbatim}

AION MAY display evidence pointer metadata.

AION MUST NOT infer goal success from a pointer alone unless the outcome scoring layer validates the evidence source summary.

AION MUST NOT perform live Gmail, CRM, analytics, booking, payment, file, or screenshot access from this preview layer.
