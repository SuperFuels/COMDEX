\section{Phase 21S --- Pilot Mission Contract Buttons}
\label{sec:aion-phase21s-pilot-contract-buttons}

\subsection{Status}

\textbf{Status: LOCKED.}

Phase 21S makes the Pilot mission contract buttons functional in the frontend.

\subsection{Purpose}

The stream UI exposed contract controls:

\begin{itemize}
  \item Approve plan;
  \item Revise plan;
  \item Cancel.
\end{itemize}

Before this phase, the buttons were visible but did not change Pilot state.

\subsection{Behavior}

\subsubsection{Approve Plan}

Approve plan changes the mission contract status to:

\begin{verbatim}
approved_for_safe_work
\end{verbatim}

This authorizes safe draft and preview work only.

It does not authorize risky or live external actions.

\subsubsection{Revise Plan}

Revise plan changes the mission contract status to:

\begin{verbatim}
revision_requested
\end{verbatim}

Pilot waits for updated instructions.

\subsubsection{Cancel}

Cancel changes the mission status to:

\begin{verbatim}
cancelled
\end{verbatim}

Pilot stops the mission without live external side effects.
