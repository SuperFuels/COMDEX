\section{Purpose}

Phase 22E.10 introduces deterministic concept-guided move re-ranking.

This phase consumes Phase 22E.9 concept-guided search and plan bias, then applies the resulting concept weights to legal candidate moves.

\section{Re-Ranking Contract}

For each re-ranked candidate move, the kernel emits:

\begin{itemize}[leftmargin=*]
  \item move UCI;
  \item base rank;
  \item re-ranked rank;
  \item base score;
  \item concept bias score;
  \item final score;
  \item applied concepts;
  \item original strategic move flag;
  \item capture/check/castle flags;
  \item re-rank reason;
  \item re-rank trace hash.
\end{itemize}

\section{Technical Position}

This phase is the first local phase where strategic concepts can change move ordering.

It still does not send moves to live Lichess. This is a no live Lichess phase.

Live-play wiring is reserved for a later phase after deterministic local re-ranking is locked.

\section{Boundary}

This phase does not use Stockfish, cloud engines, Lichess analysis, LLM move judgement, human move scoring, or live Lichess move sending.

It is deterministic local concept-guided move re-ranking over legal chess candidates.
