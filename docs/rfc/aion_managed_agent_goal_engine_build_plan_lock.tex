\subsection{Strategic Build Order}

This lock records the remaining build plan for the AION managed-agent Goal Engine sprint.

The immediate priority is to finish the Goal Engine, Workflow Canvas, dry-run runtime, Boardroom trace, evidence visibility, checkpointing, and safety contracts before moving into the external Agent-to-Agent interface.

\begin{quote}
\textbf{Finish the cockpit, execution layer, and trust layer first. Then expose the agent API as the commercial interface.}
\end{quote}

The operating model is:

\begin{itemize}
  \item \textbf{Founder UI / Boardroom:} human cockpit and trust/control layer.
  \item \textbf{Workflow Canvas:} single editing and composition surface.
  \item \textbf{Workflow Engine:} execution layer.
  \item \textbf{Evidence Trace:} trust and proof layer.
  \item \textbf{Agent API:} later commercial interface for external AI agents.
\end{itemize}

\subsection{Canvas Direction Lock}

The Workflow Canvas is the single editing and composition surface.

The separate Master Glyph Canvas mode is deprecated as a separate canvas mode. Reusable glyph workflows are managed through the Glyph Library modal and opened as tabs inside the main Workflow Canvas.

Child glyphs remain important, but they are orchestrated through parent workflows, Goal nodes, and the Glyph Library modal rather than a separate canvas surface.

\subsection{Non-Negotiable Rules}

\begin{itemize}
  \item AION is not just adding A/B testing. This is the Goal Engine / Experiment Runtime.
  \item Goal nodes define intent only. They never grant permissions.
  \item Loops, experiments, and managed-agent sessions must always be bounded by runtime, cost, iteration, write, and approval limits.
  \item Resume is not continue. Resume must revalidate approvals, vaults, connectors, budget, goal necessity, glyph state, and external environment.
  \item Checkpointing must use bounded state deltas, not ever-growing full payload history.
  \item Experiments need exploration floors so AION does not converge too early on a weak early winner.
  \item Outcome scores require evidence. Completed execution is not the same as business success.
  \item Learning is advisory only. Prior-bank, habit capsules, memory, and feedback can recommend but never bypass policy.
  \item Child glyphs are specialist agents under a parent goal.
  \item Boardroom is the trust layer. It must show what AION did, refused, learned, simulated, spent, and why.
  \item Managed-agent providers are accelerators, not the product. AION remains the orchestration OS.
  \item Version everything so goal-driven execution is reproducible and auditable.
\end{itemize}

\subsection{A2A Transition Gate}

The external Agent-to-Agent direction begins only after the following are stable:

\begin{itemize}
  \item Goal Engine contracts are present.
  \item Workflow Canvas node visibility is stable.
  \item Dry-run preview bundle is canonical.
  \item Boardroom trace visibility is stable.
  \item Evidence references and outcome scoring are visible.
  \item Safety, budget, red-team, and approval states are visible.
  \item Checkpoint/resume semantics are defined.
\end{itemize}

After this gate, AION can expose the machine-facing business-to-agent telemetry and fulfilment protocol.
