\section{Purpose}

Phase 22E.31 introduces an endgame box and mate-net builder for AION full chess.

The purpose is to convert winning endgames by reducing enemy king mobility, pushing the enemy king toward the board edge, improving own king support, and prioritising checkmate.

\section{Contract}

The kernel MUST score:

\begin{itemize}[leftmargin=*]
  \item enemy king mobility;
  \item enemy king edge distance;
  \item own king distance to the enemy king;
  \item check pressure;
  \item checkmate priority;
  \item repeated move penalties;
  \item major-piece box control.
\end{itemize}

The kernel MUST detect at least:

\begin{itemize}[leftmargin=*]
  \item \texttt{king\_queen\_vs\_king};
  \item \texttt{king\_rook\_vs\_king};
  \item \texttt{queen\_conversion};
  \item \texttt{rook\_conversion}.
\end{itemize}

\section{Boundary}

This phase does not use Stockfish, does not use LLM move judgement, and does not use Lichess analysis.
