\subsection{Purpose}

This lock adds a guarded human-review decision preview for AXO/ETS trusted feedback.

The preview supports three bounded decision states:

\begin{itemize}
  \item accept;
  \item reject;
  \item request more evidence.
\end{itemize}

The decision preview is only a review surface. It MUST NOT mutate reputation, public trust state, bookings, payments, escrow, external messages, or live execution state.

\subsection{Contract}

The locked preview contract is:

\begin{verbatim}
aion.axo_human_review_decision_preview.v0.1
\end{verbatim}

The contract requires:

\begin{itemize}
  \item \texttt{preview\_only = true};
  \item \texttt{human\_review\_required = true};
  \item \texttt{automated\_decision\_allowed = false};
  \item a valid trusted-feedback acceptance preview;
  \item \texttt{eligible\_for\_human\_review = true} before a decision can be treated as reviewable;
  \item customer outcome score and system execution score separation;
  \item all live side effects blocked.
\end{itemize}

\subsection{Safety Boundary}

  \item public trust update;
  \item booking side effects;
  \item payment side effects;
  \item escrow side effects;
  \item external message side effects;
