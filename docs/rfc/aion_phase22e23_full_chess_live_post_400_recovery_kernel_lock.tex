\section{Purpose}

Phase 22E.23 adds a recovery guard for live Lichess POST failures.

The Phase 22E.22 live rematch failed before queen endgame activation because a locally legal move returned HTTP 400 from the live server.

\section{Contract}

On HTTP 400, the runtime MUST NOT immediately abort.

It MUST:

\begin{itemize}[leftmargin=*]
  \item fetch or consume the latest game state;
  \item compare expected ply count with server ply count;
  \item detect whether the attempted move is already present;
  \item detect stale local state;
  \item detect whether the game has already finished;
  \item only hard-abort when the latest confirmed current state still rejects the move.
\end{itemize}

\section{Boundary}

This phase does not select chess moves, does not use Stockfish, does not use LLM move judgement, and does not use Lichess analysis.

It only handles live transport recovery after HTTP 400.
