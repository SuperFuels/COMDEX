\textbf{Status: LOCKED --- Pilot cockpit frontend mount contract installed.}
\end{quote}

\subsection{Purpose}

This phase defines the visible Boardroom entry point for AION Pilot.

The Pilot cockpit MUST answer the operator questions:

\begin{itemize}
  \item what is Pilot doing;
  \item what state is Pilot in;
  \item where the mission is mounted;
  \item what panels are available;
  \item whether Pilot is executing safely;
  \item whether live external action buttons are hidden by default.
\end{itemize}

\subsection{Cockpit Panels}

The cockpit shell includes:

\begin{itemize}
  \item mission composer;
  \item plan preview;
  \item Pilot stream;
  \item business container files;
  \item artifact outputs;
  \item approvals;
  \item blocked actions;
  \item mission map;
  \item proof and replay;
  \item feedback.
\end{itemize}

\subsection{Safety Contract}

The Pilot cockpit is a visible operating surface. It is not a bypass.

It MUST NOT expose raw tool execution, external mutation, live memory mutation or live action buttons by default.
