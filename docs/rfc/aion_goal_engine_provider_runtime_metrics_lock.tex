\subsection{Purpose}

This lock makes provider execution observable without granting extra autonomy.

Each provider route result MUST emit a \texttt{provider\_audit} payload containing runtime cost, token, fallback, degradation, and safety fields.

The audit payload is visibility-only. It MUST NOT authorize external writes, business state mutation, provider escalation, connector access, or permission grants.

\subsection{Canonical Provider Audit Fields}

The \texttt{provider\_audit} payload MUST include:

\begin{itemize}
  \item \texttt{trace\_type = provider\_audit}
  \item \texttt{provider}
  \item \texttt{model}
  \item \texttt{capability}
  \item \texttt{fallback\_used}
  \item \texttt{latency\_ms}
  \item \texttt{runtime\_duration\_ms}
  \item \texttt{token\_count}
  \item \texttt{prompt\_tokens}
  \item \texttt{completion\_tokens}
  \item \texttt{total\_tokens}
  \item \texttt{cost\_estimate}
  \item \texttt{degradation\_mode}
  \item \texttt{degradation\_event}
  \item \texttt{external\_writes}
  \item \texttt{business\_state\_mutation}
  \item \texttt{legacy\_business\_state\_mutation}
  \item \texttt{local\_only}
  \item \texttt{would\_grant\_permission}
  \item \texttt{failed\_closed}
  \item \texttt{error\_code}
  \item \texttt{capability\_manifest\_checked}
  \item \texttt{safe\_local\_adapter}
\end{itemize}

\subsection{Safety Invariants}

The local provider MUST remain safe by default:

\begin{itemize}
  \item \texttt{external\_writes = blocked}
  \item \texttt{business\_state\_mutation = human\_review\_guarded}
  \item \texttt{legacy\_business\_state\_mutation = blocked}
  \item \texttt{local\_only = true}
  \item \texttt{would\_grant\_permission = false}
\end{itemize}

The legacy mirror field is retained only as a compatibility shim for older audit expectations. New code SHOULD read \texttt{business\_state\_mutation}.

\subsection{Runtime Metrics}

Token and cost fields MUST be numeric and safe by default.

If a provider does not return usage, AION MUST emit numeric defaults rather than omitting the fields:

\begin{itemize}
  \item missing token counts default to \texttt{0}
  \item missing cost estimates default to \texttt{0.0}
  \item missing runtime duration defaults to provider latency
\end{itemize}

\subsection{Fallback and Degradation}

Provider fallback and degradation MUST be visible in the audit payload.

If fallback is used, \texttt{degradation\_event} SHOULD indicate provider fallback.

If provider routing fails closed, \texttt{failed\_closed} MUST be true and \texttt{error\_code} MUST describe the blocked route.

\subsection{Boardroom Contract}

Boardroom views MAY render provider metrics, fallback events, and degradation states.

Boardroom views MUST treat the payload as read-only telemetry. They MUST NOT use provider audit fields to perform writes, mutate goals, escalate permissions, or mark work complete.
