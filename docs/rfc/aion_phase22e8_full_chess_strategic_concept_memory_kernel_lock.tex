\section{Purpose}

Phase 22E.8 introduces deterministic strategic concept memory for the AION chess stack.

This phase consumes Phase 22E.7 consequence and risk forecasts, then converts recurring plan and risk patterns into reusable named strategic concepts.

\section{Concept Contract}

Each strategic concept contains:

\begin{itemize}[leftmargin=*]
  \item concept identifier;
  \item concept name;
  \item source stage goal;
  \item source trigger feature;
  \item trigger features;
  \item primary goal;
  \item preferred actions;
  \item success rate;
  \item usage count;
  \item average risk reduction;
  \item policy weight;
  \item fallback concepts;
  \item concept reason;
  \item use condition;
  \item preferred response;
  \item fallback response;
  \item reinforcement score;
  \item observed count;
  \item concept trace hash.
\end{itemize}

\section{Canonical Concepts}

The initial concept memory supports:

\begin{itemize}[leftmargin=*]
  \item king safety recovery;
  \item invasion pressure reduction;
  \item promotion defence protocol;
  \item development before attack;
  \item centre control before conversion;
  \item piece activity recovery;
  \item safe endgame conversion.
\end{itemize}


\section{Concept Application Contract}

The concept memory also emits application telemetry for future integration into search and planning layers:

\begin{itemize}[leftmargin=*]
  \item applied concepts for the current run;
  \item strongest concept;
  \item plan alignment with concepts;
  \item policy weight per concept;
  \item concept success rate;
  \item average risk reduction per concept.
\end{itemize}

Phase 22E.8 does not yet wire concepts into live move execution. That integration is reserved for Phase 22E.9.

\section{Technical Position}

This phase does not prove open-ended chess understanding.

It creates deterministic reusable concept memory from recurring AION plan and risk telemetry.

\section{Boundary}

This phase does not use Stockfish, cloud engines, Lichess analysis, LLM move judgement, or human move scoring.

It is deterministic local strategic concept memory over AION chess telemetry.
