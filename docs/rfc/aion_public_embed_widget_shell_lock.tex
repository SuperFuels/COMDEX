\subsection{Purpose}

Phase 12A created the backend Public Website Intent Gateway preview.

Phase 12B adds the first visible frontend shell for the future public website embed layer.

The shell is a preview-only UI surface for showing how website forms, buttons, and embedded chat widgets will connect to the guarded AION Gateway.

This phase does not submit live website requests. It does not mount a production embed script. It does not create a booking, live job, payment, escrow, fund release, PHO movement, wallet requirement, or external message.

\subsection{Implemented Surface}

The implementation is appended to:

\begin{verbatim}
desktop/mac/src/app.js
\end{verbatim}

\begin{verbatim}

\begin{verbatim}

\end{verbatim}

\end{verbatim}

The lock marker is:

\begin{verbatim}

\end{verbatim}

\subsection{Supported Preview Surfaces}

The shell lists the future public website surfaces:

\begin{itemize}
  \item \texttt{embed\_script\_preview}
  \item \texttt{website\_form\_widget\_preview}
  \item \texttt{website\_button\_widget\_preview}
  \item \texttt{embedded\_chat\_widget\_preview}
\end{itemize}

These are frontend preview surfaces only.

\subsection{Gateway Mapping}

The shell documents the intended human-to-machine mapping:

\begin{verbatim}
human form -> NormalizedInboundIntent
widget request -> MachineCartRequest
gateway preview -> public_intent_gateway
\end{verbatim}

This keeps the human website layer aligned with the same machine-readable Gateway contracts used by the A2A layer.

\subsection{Required Guards}

The preview shell marks the following guards as required:

\begin{itemize}
  \item tenant/business key validation,
  \item signed request validation,
  \item rate limiting,
  \item abuse protection,
  \item human review.
\end{itemize}

These guards must be enforced before any public write route becomes live.

\subsection{Safety Boundary}

The Public Website Embed Widget Shell MUST NOT:

\begin{itemize}
  \item create a booking,
  \item create a live job,
  \item execute the Goal Engine,
  \item bypass human review,
  \item move money,
  \item move PHO,
  \item require a wallet,
  \item create a payment,
  \item create escrow,
  \item release funds,
  \item send external messages,
  \item expose an unauthenticated public write route.
\end{itemize}

The locked safety flags include:

\begin{verbatim}
