\subsection{Purpose}

Phase 21D connects the frontend to the Phase 21C local preview endpoint.

It loads the AION-LRM Pilot Context Preview into the existing Pilot frontend state.

This phase does not redesign the Pilot interface and does not create a duplicate Pilot surface.

\subsection{Endpoint}

The bridge fetches:

\begin{verbatim}
/api/local-node/aion/lrm/pilot-context-preview
\end{verbatim}

\subsection{Implemented Frontend Functions}

The live frontend file is:

\begin{verbatim}
desktop/mac/src/app.js
\end{verbatim}

Phase 21D adds:

\begin{verbatim}
getAionLrmPilotContextPreviewUrl
applyAionLrmPilotContextPreviewPayload
fetchAionLrmPilotContextPreviewIntoPilotState
\end{verbatim}

The bridge writes into the existing Pilot state returned by:

\begin{verbatim}
getAionPilotFrontendInteractionState
\end{verbatim}

\begin{verbatim}

\begin{itemize}

  \item redesign the Pilot UI;
  \item create a booking;
  \item create a payment;
  \item create escrow;
  \item send an external message;
  \item write live chain data;
  \item execute workflow steps;
  \item write business-container files;
  \item expose private chain-of-thought;
  \item expose hidden reasoning;
  \item expose credentials.
\end{itemize}
