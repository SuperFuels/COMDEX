\section{Phase 21A --- Pilot Cockpit UI Contract}
\label{sec:aion-phase21a-pilot-cockpit-ui-contract}

\subsection{Status}

Phase 21A installs the first visible Pilot cockpit contract.

\begin{quote}
\textbf{Status: LOCKED --- Pilot cockpit read-model contract installed.}
\end{quote}

\subsection{Purpose}

The Pilot cockpit makes AION Pilot visible to the user.

It shows the mission stream, plan state, generated artifacts, approval cards, blocked actions, feedback controls, proof, replay, receipts and ETS preview.

\subsection{Non-Execution Rule}

The cockpit is a read model.

It MAY show plans, files, previews, blocked actions and approval payloads.

It MUST NOT execute raw tools, submit payments, deploy production, send external messages, create bookings, create escrow, publish posts or mutate live reputation.

\subsection{Artifact Visibility}

Generated artifacts MUST show:

\begin{itemize}
  \item artifact type;
  \item business container path;
  \item mission identifier;
  \item run identifier;
  \item step identifier;
  \item artifact hash;
  \item draft or preview status.
\end{itemize}

\subsection{Feedback Boundary}

User feedback MUST be captured as governed feedback events.

Feedback MUST NOT silently mutate live memory, reusable templates, provider state or reputation.
