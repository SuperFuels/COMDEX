\section{AION Phase 20H.1 --- External Tool Gateway}
\label{sec:aion-phase20h1-external-tool-gateway}

\subsection{Status}

Phase 20H.1 locks the External Tool Gateway.

\begin{quote}
\textbf{Status: LOCKED --- AION Pilot may access external capabilities only through a governed gateway contract.}
\end{quote}

\subsection{Purpose}

The External Tool Gateway is the safe bridge between AION Pilot and external capabilities.

It enables OpenClaw-style tool power while preventing raw, uncontrolled tool usage.

\subsection{Core Rule}

AION Pilot MAY use tools.

The model MUST NOT call raw tools directly.

All external tool calls MUST pass through:

\begin{itemize}
  \item capability registry;
  \item tool mode classification;
  \item provider boundary;
  \item payload approval checks for live tools;
  \item gateway evaluation;
  \item deterministic tool call hash;
  \item receipt generation where execution occurs.
\end{itemize}

\subsection{Tool Modes}

The gateway defines:

\begin{itemize}
  \item \texttt{safe\_internal};
  \item \texttt{read\_only\_external};
  \item \texttt{staged\_external};
  \item \texttt{approved\_live\_external}.
\end{itemize}

\subsection{Live External Action Rule}

Any \texttt{approved\_live\_external} tool MUST require:

\begin{itemize}
  \item approved payload hash;
  \item approval hash;
  \item approval expiry;
  \item exact payload match;
  \item unexpired approval.
\end{itemize}
