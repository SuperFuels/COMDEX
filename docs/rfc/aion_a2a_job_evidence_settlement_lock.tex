\subsection{Purpose}

Phase 11E adds the next machine-facing preview layer inside the guarded A2A Gateway.

It covers:

\begin{itemize}
  \item \texttt{job\_evidence}
  \item \texttt{settlement\_readiness}
\end{itemize}

The job evidence preview allows an external agent to inspect required evidence, submitted evidence, missing evidence, and evidence-backed completion state.

The settlement readiness preview allows an external agent to inspect whether a job is ready for future guarded fiat settlement.

This remains preview-only. It does not move money, create a payment, create escrow, release funds, execute a workflow, or bypass human review.

\subsection{Evidence Boundary}

The evidence preview is explicitly non-live.

The locked fields include:

\begin{verbatim}
human_review_required = true
evidence_review_status = requires_human_review
final_completion_confirmed = false
\end{verbatim}

The evidence preview may indicate whether all required evidence is present, but it MUST NOT confirm final completion without human review.
