\subsection{Purpose}

The purpose of this lock is to ensure that multi-agent and multi-glyph orchestration history is not only rendered as a transient Boardroom preview.

AION now has a replay history path with two layers:

\begin{itemize}
  \item a Boardroom-local replay history stored through guarded \texttt{localStorage};
  \item a backend replay history record contract suitable for later durable business-container persistence.
\end{itemize}

This means the Boardroom can show recent orchestration replay snapshots without granting execution permission, while the backend can build canonical replay-history records without mutating goals, executing child agents, resolving conflicts, or writing externally.

\subsection{Safety Invariants}

Replay history is visibility-only.

AION MUST NOT use replay-history recording to:

\begin{itemize}
  \item execute child agents;
  \item execute child glyphs;
  \item mutate parent goals;
  \item mark parent goals complete;
  \item resolve conflicts automatically;
  \item select a winning child agent;
  \item write externally;
  \item grant connector permissions;
  \item bypass approval gates.
\end{itemize}

The backend replay-history record therefore locks the following flags:

\begin{verbatim}
dry_run                 = true
visibility_only         = true
execution_allowed       = false
writes_allowed          = false
parent_mutation_allowed = false
child_execution_allowed = false
\end{verbatim}

The canonical blocked reasons include:

\begin{verbatim}
visibility_only
human_review_required
backend_replay_history_does_not_execute
\end{verbatim}
