\section{Purpose}

Phase 22E.24 integrates the Phase 22E.23 HTTP 400 recovery guard into the Phase 22E.22 full Level-2 live rematch loop.

The live loop MUST NOT abort immediately when a move POST returns HTTP 400.

\section{Contract}

The live rematch loop MUST:

\begin{itemize}[leftmargin=*]
  \item invoke Phase 22E.23 on HTTP 400;
  \item continue when the latest server state shows the move was already applied;
  \item continue when stale-state server advancement is detected;
  \item refresh from the latest server move list after nonfatal recovery;
  \item count the recovered move as sent and successful;
  \item hard-abort only when the latest current state confirms rejection.
\end{itemize}

\section{Boundary}

This phase does not select chess moves, does not send moves, does not use Stockfish, does not use LLM move judgement, and does not use Lichess analysis.

It only defines the deterministic recovery decision contract for the live rematch loop.
