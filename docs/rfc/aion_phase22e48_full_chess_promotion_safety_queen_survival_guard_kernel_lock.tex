\section{Purpose}

Phase 22E.48 adds a promotion safety guard above the dynamic intent switching stack.

The purpose is to prevent AION from promoting to a queen when the promoted queen can be immediately captured or when the promotion permits immediate mate.

\section{Failure Source}

The Level-3 live game exposed the following sequence:

\begin{verbatim}
g6g7
g7g8q
...
g1g8
\end{verbatim}

AION successfully created a passed pawn and promoted it to a queen. However, the promoted queen did not survive conversion.

\section{Rule}

If the selected move is a promotion, the guard MUST check whether the promoted piece can be immediately captured by the opponent.

If the promoted queen is immediately capturable, or if the move permits immediate mate, the guard SHOULD select a safe legal alternative when one exists.
