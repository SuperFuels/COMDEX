\section{Purpose}

Phase 22E.2 introduces multi-ply strategic search with goal bias.

This phase consumes the Phase 22E.1 positional features layer and uses those features inside deterministic search scoring.

\section{Search Contract}

The kernel evaluates candidate move lines using:

\begin{itemize}[leftmargin=*]
  \item multi-ply legal move search;
  \item positional score after candidate moves;
  \item positional delta from the starting position;
  \item goal bias over king safety, promotion defence, invasion reduction, repetition reduction, activity, centre control, and passed pawns;
  \item deterministic trace hashing.
\end{itemize}

\section{Goal Biases}

The locked goal biases are:

\begin{itemize}[leftmargin=*]
  \item defend king;
  \item stop promotion;
  \item reduce invasion;
  \item reduce repetition;
  \item improve piece activity;
  \item improve centre control;
  \item improve passed-pawn potential.
\end{itemize}

\section{Boundary}

This phase does not use Stockfish, cloud engines, Lichess analysis, LLM move judgement, or human move scoring.

It is deterministic local search using AION positional feature telemetry.
