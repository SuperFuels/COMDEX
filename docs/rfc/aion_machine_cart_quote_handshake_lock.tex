\subsection{Status}

The AION Gateway now defines the first internal machine-cart quote preview for the Home Fixed Parallel Business Twin.

\begin{quote}
\textbf{Status: LOCKED --- internal quote preview only. No booking, no payment, no escrow, no public route, and no live Goal Engine execution.}
\end{quote}

\subsection{Purpose}

The Machine Cart is the agent-readable checkout surface for the Parallel Business Twin.

It is not a human shopping cart. It has no conversion UI, no visual checkout flow, and no payment movement. It is a deterministic validation container used by agents to request a service, declare constraints, validate evidence requirements, and receive a structured quote preview.

\subsection{Validation Rules}

The cart preview MUST:

\begin{itemize}
  \item validate that \texttt{business\_id} matches the catalog,
  \item validate that each \texttt{service\_key} exists,
  \item validate that \texttt{location\_town} is supported,
  \item return required evidence for the requested service,
  \item warn when required evidence is missing,
  \item return a \texttt{QuoteContract}-style preview without live execution.
\end{itemize}

\subsection{Hashing Rule}

The cart and quote hashes are computed from deterministic JSON:

\begin{verbatim}
json.dumps(payload, sort_keys=True, separators=(",", ":"))
hashlib.sha256(...)
\end{verbatim}

The \texttt{cart\_hash} MUST be stable for the same request payload.

Changing the requested service MUST change the \texttt{quote\_hash}.

\subsection{Safety Boundary}

This lock is internal and preview-only.

The Machine Cart MUST NOT:

\begin{itemize}
  \item create a booking,
  \item create a payment,
  \item create escrow,
  \item execute the Goal Engine,
  \item expose a public route,
  \item move money,
  \item move PHO,
  \item require a wallet,
  \item autonomously create a FulfilmentJob.
\end{itemize}

Human review remains required by default.

\subsection{Strategic Role}

This module is the first concrete version of the agent-readable shopping cart for AION's Parallel Business Infrastructure.

Human customers can still use normal websites and forms. Consumer agents will eventually use this cart handshake to request services from the machine-readable business twin.
