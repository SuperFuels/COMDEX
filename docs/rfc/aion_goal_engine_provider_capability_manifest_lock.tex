Local provider rule:

local provider is local_only.
local external_writes are blocked.
local can support drafting, summarization, classification, and analysis.
local is not allowed to mutate business state directly.

Cloud provider rule:

openai and anthropic may support reasoning, planning, drafting, analysis, summarization, and multi-agent orchestration.
cloud external writes require approval.
business state mutation still requires guarded container write and human review.

Routing rule:

ProviderRouter MUST check provider capability before routing.
Unsupported provider capability MUST fail closed with provider_capability_not_supported.
Router payloads MUST include capability_manifest_checked when capability routing rejects a provider.

Boardroom rule:

Boardroom MUST expose provider_capability_manifest for operator visibility.
Boardroom UI may render provider disclosure, but MUST NOT use provider manifest as storage.
