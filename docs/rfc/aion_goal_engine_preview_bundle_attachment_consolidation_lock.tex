\subsection{Purpose}

This lock prevents Goal Engine runtime previews from drifting into separate standalone/demo-only paths.

The following runtime summaries now travel through the normal preview bundle path:

\begin{itemize}
  \item parent-child orchestrator aggregation;
  \item goal decomposition;
  \item tiered memory.
\end{itemize}

The canonical path is:

\begin{verbatim}
Goal contracts / manifest
  -> dry-run manifest
  -> GoalEnginePreviewBundle
  -> machine_trace
  -> dry-run bridge payload
  -> Boardroom live payload
\end{verbatim}

\subsection{Parent-Child Aggregation Attachment}

Parent-child aggregation is exposed through:

\begin{verbatim}
parent_child_aggregation_runtime_summary
orchestrator_parent_child_aggregation_runtime_summary
parent_child_aggregation_previews
orchestrator_parent_child_aggregation_previews
\end{verbatim}

The runtime summary MUST remain dry-run only.

It MUST NOT:

\begin{itemize}
  \item execute child runs;
  \item mutate a parent goal;
  \item choose a winning child agent;
  \item grant permission;
  \item write externally.
\end{itemize}

Required safety fields:

\begin{verbatim}
dry_run_only = true
would_mutate_parent_goal = false
would_grant_permission = false
would_write_external = false
\end{verbatim}

\subsection{Goal Decomposition Attachment}

Goal decomposition is exposed through:

\begin{verbatim}
goal_decomposition_runtime_summary
goal_engine_decomposition_runtime_summary
goal_decomposition_previews
decomposition_previews
child_goal_previews
\end{verbatim}

The runtime summary MUST preserve child/sub-goal rows as preview-only records.

It MUST NOT:

\begin{itemize}
  \item create real child goals;
  \item mutate the parent goal;
  \item expand the workflow automatically;
  \item grant permission.
\end{itemize}

Required safety fields:

\begin{verbatim}
dry_run_only = true
would_create_child_goals = false
would_mutate_parent_goal = false
would_grant_permission = false
\end{verbatim}

Compatibility mirrors MUST NOT become separate sources of truth.
