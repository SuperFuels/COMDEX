\subsection{Purpose}

This lock proves that AION can transform a guarded child-agent handoff into a visible, review-only child-run creation packet without directly creating a Workflow Capsule run, executing a child agent, writing externally, mutating business state, or granting permissions.

The locked chain is:

\begin{verbatim}
guarded_child_agent_execution_handoff
  -> guarded_child_run_creation_request
  -> human_approved_child_run_creation_action
  -> runtime_seed
  -> child_run_executor_bridge_packet
  -> child_run_executor_bridge_runtime_summary
  -> GoalEnginePreviewBundle
\end{verbatim}

\subsection{Runtime Seed Requirement}

The \texttt{runtime\_seed} field is the canonical handoff boundary between human approval and Workflow Capsule runtime creation.

The executor bridge MUST trust only canonical identifiers inside \texttt{runtime\_seed}. Outer action fields are provenance only and MUST NOT be used as trusted runtime creation inputs.

Required \texttt{runtime\_seed} fields include:

\begin{verbatim}
workflow_id
run_id
parent_goal_id
child_goal_id
child_agent_id
child_glyph_id
created_by
requires_runtime_executor
external_writes_allowed
business_mutation_allowed
source_request_schema_version
source_request_trace_type
\end{verbatim}

The legacy \texttt{child\_run\_seed} field MAY remain present for compatibility, display, and older preview consumers, but it is not the canonical executor input. The canonical runtime bridge MUST use \texttt{runtime\_seed}.

\subsection{Safety Invariants}

The guarded child-run E2E chain MUST remain review-only until an explicit runtime executor consumes the approved bridge packet.

The chain MUST NOT:

\begin{itemize}
  \item execute a child agent directly;
  \item create a Workflow Capsule run directly from the parent preview path;
  \item write to external systems;
  \item mutate business containers;
  \item mutate parent goals;
  \item mutate child goals;
  \item grant permissions;
  \item bypass the human approval boundary.
\end{itemize}

The canonical safety flags are:

\begin{verbatim}
dry_run = true
visibility_only = true
execution_allowed = false
writes_allowed = false
child_run_created = false
autonomous_execution = false
external_writes_allowed = false
business_mutation_allowed = false
creates_external_side_effects = false
\end{verbatim}

\subsection{Locked Failure Modes}

The chain MUST block when:

\begin{itemize}
  \item the guarded request is invalid;
  \item the request is missing required parent or child goal identifiers;
  \item the request is missing target workflow or child-run identifiers;
  \item the human approval decision is not \texttt{approved};
  \item the reviewer is missing;
  \item \texttt{runtime\_seed} is missing;
  \item \texttt{runtime\_seed.workflow\_id} is missing;
  \item \texttt{runtime\_seed.run\_id} is missing.
\end{itemize}

The request must expose \texttt{child\_run\_creation\_request\_valid}; the approved action must expose canonical \texttt{runtime\_seed}; and the executor bridge must trust only \texttt{runtime\_seed}.
\end{quote}
