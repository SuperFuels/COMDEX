\subsection{Purpose}

The bridge proves that a synthetic external agent flow can reach a safe operator review state without creating live side effects.

The flow is:

\begin{enumerate}
  \item Build AgentMap discovery preview.
  \item Verify AgentMap live verification preview.
  \item Run synthetic inbound-agent simulation.
  \item Create a preview-only human review request.
  \item Halt at \texttt{waiting\_human\_review}.
\end{enumerate}

\subsection{Human Review Boundary}

The generated review request is preview-only and synthetic-only.

It MUST set:

\begin{verbatim}
status = waiting_human_review
preview_only = true
synthetic_only = true
human_review_required = true
live_execution_authorized = false
\end{verbatim}

Allowed preview actions are limited to:

\begin{verbatim}
approve_preview_only
reject_preview_only
request_more_information_preview_only
\end{verbatim}

These actions MUST NOT execute live work.
