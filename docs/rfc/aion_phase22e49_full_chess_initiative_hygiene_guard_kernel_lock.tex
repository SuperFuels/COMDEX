\section{Purpose}

Phase 22E.49 adds an initiative hygiene guard above the promotion safety stack.

The purpose is to prevent AION from playing wing-pawn lunges under \texttt{initiative\_pressure} unless the move is concrete.

\section{Failure Source}

The Level-3 game exposed repeated initiative drift:

\begin{verbatim}
h2h4
g2g4
a2a3
\end{verbatim}

These moves were legal, but they were not concrete enough against Level 3.

\section{Rule}

Under \texttt{initiative\_pressure}, AION SHOULD reject wing-pawn lunges unless the move is one of:

\begin{itemize}
  \item a capture;
  \item check or mate;
  \item a promotion path;
  \item a king-safety necessity;
  \item otherwise concretely forcing.
\end{itemize}
