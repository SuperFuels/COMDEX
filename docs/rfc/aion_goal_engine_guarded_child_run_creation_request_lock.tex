\subsection{Purpose}

This lock closes the gap between a visible guarded child-agent handoff and an executable child-run creation request.

The contract does not create the child run directly. It produces a review-only request packet that preserves parent and child links, target workflow identity, target run identity, glyph identity, and safety flags. The actual child workflow run remains blocked until a human-approved runtime layer consumes the request.

\subsection{Safety Invariants}

The request is deliberately non-autonomous.

It MUST NOT:

\begin{itemize}
  \item create a workflow run directly;
  \item execute a child agent;
  \item mark a parent goal complete;
  \item resolve a conflict automatically;
  \item write externally;
  \item grant permissions;
  \item bypass human approval.
\end{itemize}

The field:

\begin{verbatim}
child_run_created
\end{verbatim}

MUST remain false at this stage.

The request MAY become eligible for a downstream approval-action runtime, but only after the handoff has been marked ready for execution handoff and a target workflow plus child run identifier are both present.
