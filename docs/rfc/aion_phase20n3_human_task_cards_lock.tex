\section{AION Phase 20N.3 --- Human Task Cards and Evidence Binding}
\label{sec:aion-phase20n3-human-task-cards-evidence-binding}

\subsection{Status}

Phase 20N.3 locks Human Task Cards and Evidence Binding.

\begin{quote}
\textbf{Status: LOCKED --- human-required work is a first-class mission pause, not a failure.}
\end{quote}

\subsection{Purpose}

Some business tasks cannot or should not be completed by AION Pilot.

Examples include:

\begin{itemize}
  \item creating a real Facebook account;
  \item verifying a phone number;
  \item uploading identity documents;
  \item answering provider verification calls;
  \item taking real job photos;
  \item signing legal documents;
  \item approving card ownership;
  \item providing provider account access.
\end{itemize}

These tasks MUST pause the mission without marking it failed.

\subsection{Human Task Card Contract}

A Human Task Card MUST include:

\begin{itemize}
  \item human task ID;
  \item mission ID;
  \item mission run ID;
  \item step ID;
  \item title;
  \item reason;
  \item instructions;
  \item required evidence type;
  \item required evidence fields;
  \item blocking status;
  \item resume condition;
  \item provider;
  \item task hash.
\end{itemize}

\subsection{Evidence Binding}

Human task completion MUST be evidence-bound.

Supported evidence types include:

\begin{itemize}
  \item URL;
  \item screenshot hash;
  \item confirmation code;
  \item uploaded file hash;
  \item manual attestation;
  \item provider callback.
\end{itemize}

Evidence MUST emit:

\begin{verbatim}
evidence_hash: sha256:<digest>
\end{verbatim}

\subsection{Resume Rule}

A mission may resume only when required evidence is present and validated.

If evidence is missing or incomplete, the mission MUST remain in:

\begin{verbatim}
waiting_human_task
\end{verbatim}

If evidence is valid, the mission MAY transition back to:

\begin{verbatim}
running_autonomous_steps
\end{verbatim}

\subsection{Example Human Task}

\begin{verbatim}
Human Task Required:
Create or connect Facebook Business Page.

Why:
Facebook requires real account ownership and may require identity or phone verification.

What to do:
1. Log in to Facebook using the real business owner account.
2. Create or connect the business page.
3. Add phone number, service area and category.
4. Return to AION and submit the Facebook Page URL.

Required evidence:
page_url
\end{verbatim}
