\subsection{Manual Smoke Checklist}

Run the local desktop application and confirm:

\begin{itemize}
  \item the desktop app starts without JavaScript syntax failure,
  \item the Boardroom view opens,
  \item the Home Fixed Parallel Twin panel is visible,
  \item the Parallel Twin payload mount or fallback payload renders,
  \item summary cards are visible,
  \item payload hash, business identifier, job identifier, and vertical key are visible,
  \item proof status is visible,
  \item exception state is visible,
  \item human review status is visible,
  \item Founder Override preview controls are visible,
  \item Founder Override controls are disabled,
  \item no live execute button appears,
  \item no booking, payment, escrow, wallet, PHO, or external message action appears.
\end{itemize}

  \item execute the Goal Engine,

  \item require a wallet,
  \item create a payment,
  \item create escrow,
  \item send external messages,
