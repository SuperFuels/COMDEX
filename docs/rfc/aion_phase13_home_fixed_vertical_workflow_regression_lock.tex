\subsection{Locked Contract}

The Home Fixed vertical workflow MUST:

\begin{itemize}

  \item Use real home repair/service vocabulary such as repair, quote, customer, and job.
  \item Remain safe for public embed and public-intent preview flows.
  \item Surface \texttt{human\_review\_required} before operational execution.
  \item Keep booking, payment, escrow, job dispatch, and external messaging as blocked preview flags.
  \item Avoid live provider imports for messaging, payment, booking, calendar, or dispatch systems.
\end{itemize}
