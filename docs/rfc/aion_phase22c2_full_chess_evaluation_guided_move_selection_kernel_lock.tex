\section{Purpose}

Phase 22C.1 gave AION a deterministic local position evaluator.

Phase 22C.2 uses that evaluator to score every legal candidate move and select the highest-scoring legal move.

\section{Selection Contract}

The kernel MUST:

\begin{itemize}
  \item generate legal chess moves;
  \item score each candidate using the Phase 22C.1 evaluator;
  \item select the highest-scoring legal move;
  \item prioritise terminal mate moves when detected;
  \item avoid emitting moves from terminal positions;
  \item emit a deterministic trace hash;
  \item avoid Stockfish, cloud engines, and LLM move judgement.
\end{itemize}
