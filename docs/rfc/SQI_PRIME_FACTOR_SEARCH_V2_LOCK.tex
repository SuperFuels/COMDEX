\section{Purpose}

This lock records a working SQI-style factor-search prototype where integer factorisation
is treated as a symbolic branch-routing and collapse problem.

Given an integer \(N\), the system creates a strategy space:

\[
N
\rightarrow
\left\{
\text{small-prime},
\text{Fermat},
\text{Brent Rho},
\text{Pollard Rho},
\text{wheel/coherence}
\right\}
\rightarrow
\text{branch routing}
\rightarrow
\text{verified collapse}.
\]

A candidate factor \(d\) is accepted only when:

\[
N \bmod d = 0.
\]

Thus symbolic scoring and branch routing guide the search, but exact divisibility remains
the final collapse condition.

\section{Branch Types}

\subsection{Small-Prime Branch}

This branch checks a fixed small-prime table. If a small divisor exists, collapse is immediate:

\[
N = p \cdot \frac{N}{p}.
\]

\subsection{Fermat Branch}

The Fermat branch targets near-square semiprimes:

\[
N = a^2 - b^2 = (a-b)(a+b).
\]

It performs well when the two factors of \(N\) are close together.

\subsection{Pollard Rho Branch}

The Pollard Rho branch targets broader composite integers by detecting a non-trivial divisor:

\[
1 < \gcd(|x-y|, N) < N.
\]

\subsection{Brent Rho Branch}

Version 2 adds Brent's variant of Pollard Rho. This usually reduces the number of expensive
\(\gcd\) operations by batching progress before checking for a divisor.

\subsection{Wheel/Coherence Branch}

The wheel branch generates candidates coprime to \(2\), \(3\), and \(5\). Each candidate
receives a coherence score based on exact divisibility, small-prime contradiction pruning,
modulo residue closeness, and depth penalty.

\section{Adaptive Routing}

The router estimates whether \(N\) is close to a square using:

\[
g = \lceil\sqrt{N}\rceil^2 - N.
\]

For near-square candidates:

\[
\text{Fermat}
\rightarrow
\text{Brent Rho}
\rightarrow
\text{Pollard Rho}
\rightarrow
\text{SQI wheel}.
\]

For spread candidates:

\[
\text{Brent Rho}
\rightarrow
\text{Pollard Rho}
\rightarrow
\text{Fermat}
\rightarrow
\text{SQI wheel}.
\]

\section{Branch-Budget Scheduling}

Version 2 introduces an interleaved branch-budget scheduler. Instead of running each branch
to completion in a fixed order, the scheduler gives bounded execution budgets to each
strategy branch according to routing order.

\section{Interpretation}

SQI-adaptive is not always the fastest method because it carries trace, dashboard, routing,
and scheduler overhead. In small cases, naive division or standalone Brent Rho can be faster.

The useful result is architectural:

\begin{quote}
SQI can route factor search across symbolic strategy branches, interleave branch budgets,
emit auditable traces, and collapse only on verified mathematical proof.
\end{quote}

The observed routing behaviour is correct:

\begin{itemize}
  \item close semiprimes route to Fermat;
  \item spread-factor composites route to Brent/Pollard-style Rho;
  \item collapse only occurs after exact divisibility is verified.
\end{itemize}

\section{Known Issues}

\subsection{Overhead on Small Inputs}

For small composites, SQI-adaptive can be slower than naive or standalone Brent because of
trace and dashboard overhead. This is expected.

\subsection{Scheduler Is Initial}

The scheduler is currently budget-based, not fully coherence-adaptive. A future scheduler should
adjust branch budgets according to observed progress and collapse likelihood.
