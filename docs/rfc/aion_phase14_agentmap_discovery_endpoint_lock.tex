\subsection{Purpose}

Phase 14C locks the preview contract for the future AgentMap discovery endpoint.

The endpoint preview declares the machine-readable discovery paths:

\begin{verbatim}
/agentmap.json
/.well-known/agentmap.json

This phase is read-only and preview-only.

It prepares the route contract that future websites, dashboards, and external agents will use to discover the AgentMap for an AION-enabled business.

\subsection{Endpoint Contract}

The locked preview declares two discovery paths:

\begin{itemize}
  \item \texttt{/agentmap.json}
  \item \texttt{/.well-known/agentmap.json}
\end{itemize}

The endpoint preview allows only read methods:

\begin{verbatim}
GET
HEAD
\end{verbatim}

The endpoint preview forbids write methods:

\begin{verbatim}
POST
PUT
PATCH
DELETE
\end{verbatim}

The locked public route state is:

\begin{verbatim}
route_exposed = false
public_route_mounted = false
preview_only = true
read_only = true
\end{verbatim}

This means Phase 14C declares the read-only endpoint shape but does not mount a live public route.

\subsection{Hash Contract}

The endpoint preview exposes deterministic hash fields:

\begin{itemize}
  \item \texttt{agentmap\_hash}
  \item \texttt{endpoint\_hash}
  \item \texttt{summary\_hash}
\end{itemize}

The \texttt{agentmap\_hash} anchors the generated AgentMap payload.

The \texttt{endpoint\_hash} anchors the discovery endpoint preview response.

The \texttt{summary\_hash} anchors the minimal read-only endpoint summary.

These hashes are replay and audit anchors only.

They MUST NOT grant permissions, create bookings, create live jobs, move money, create payments, create escrow, release funds, dispatch work, send external messages, or write live chain data.
