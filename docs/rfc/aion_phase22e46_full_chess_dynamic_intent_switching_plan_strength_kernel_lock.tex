\section{Purpose}

Phase 22E.46 adds dynamic intent switching and plan strength evaluation to the live chess stack.

The purpose is to stop AION from staying inside a stale plan after the board state has changed.

\section{Problem}

The Phase 22E.45 live win proved that AION can win a live Level-2 game by mate.

However, the game also showed that AION can remain inside \texttt{initiative\_pressure} after the opening, even when the position may require:

\begin{itemize}
  \item simplification while ahead;
  \item direct king safety response;
  \item opponent plan disruption;
  \item sharper conversion policy;
  \item a transition from development to attack.
\end{itemize}

\section{Rule}

AION SHOULD keep the current intent only while the plan remains strong.

AION SHOULD switch intent when:

\begin{itemize}
  \item development is complete and \texttt{rapid\_development} should become \texttt{initiative\_pressure};
  \item material advantage is high enough to justify \texttt{simplify\_when\_ahead};
  \item king safety pressure requires \texttt{king\_safety};
  \item opponent threat pressure requires \texttt{neutralise\_critical\_threat};
  \item the active plan falls below the plan strength threshold.
\end{itemize}
