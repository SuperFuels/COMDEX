\subsection{Packaged Runtime Resolver}

O23F added an app-local resolver for voice runtime selection.

The resolver supports the following priority order:

\begin{enumerate}
  \item Explicit \texttt{AION\_VOICE\_PYTHON} override.
  \item Explicit \texttt{AION\_VOICE\_BUNDLE\_ROOT} override.
  \item Staging bundle mode.
  \item Packaged app mode.
  \item Development fallback only where allowed.
\end{enumerate}

The resolver can identify both the staging bundle path and the future packaged app path:

\begin{verbatim}
desktop/mac/voice_bundle_staging/voice
desktop/mac/Tessaris.app/Contents/Resources/voice
\end{verbatim}

In the current repository state, packaged mode correctly reports that the final embedded runtime does not yet exist.

\subsection{No-Hidden-Downloads Lock}

O23H added a no-hidden-downloads runtime policy.

In staging and packaged voice modes, the worker environment is locked with:

\begin{verbatim}
HF_HUB_OFFLINE=1
TRANSFORMERS_OFFLINE=1
HF_DATASETS_OFFLINE=1
HF_HUB_DISABLE_TELEMETRY=1
TOKENIZERS_PARALLELISM=false
AION_VOICE_NO_HIDDEN_DOWNLOADS=true
AION_ELEVENLABS_ENABLED=false
AION_BROWSER_SPEECH_FALLBACK_ENABLED=false
\end{verbatim}

This prevents silent Hugging Face, Transformers, spaCy, ElevenLabs, or browser speech fallback behavior in packaged voice operation.
