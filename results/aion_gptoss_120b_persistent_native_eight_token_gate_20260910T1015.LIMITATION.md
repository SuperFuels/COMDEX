# LIMITATION

The eight-token execution is numerically valid and exactly repeatable, but it
falsifies promotion of the 3 GiB raw LRU as a sustained-generation strategy.
The cumulative route grew to 661 layer/expert pairs (about 8.76 GB raw), and
opening-run average throughput was only 0.0322 token/s. Use the report as
working-set evidence, not as an interactive-speed claim.
